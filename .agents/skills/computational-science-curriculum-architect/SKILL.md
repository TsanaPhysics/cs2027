# 🧬 Computational Science Curriculum Architect
**มาตรฐานการออกแบบบทเรียนและสื่อการเรียนรู้วิทยาการคำนวณสำหรับการสอนวิทยาศาสตร์**  
**ผู้พัฒนา:** ผู้ช่วยศาสตราจารย์ ดร.ชีวะ ทัศนา  
**สังกัด:** คณะวิทยาศาสตร์และเทคโนโลยี มหาวิทยาลัยราชภัฏรำไพพรรณี  
**รายวิชา:** 4124941 วิทยาการคำนวณสำหรับการสอนวิทยาศาสตร์ (3 หน่วยกิต 2-2-5)

## 🏛️ 1. ปรัชญาและรากฐานทางทฤษฎี (Theoretical Foundations)

ทุกบทเรียนตั้งแต่สัปดาห์ที่ 1 ถึง 16 ต้องตั้งอยู่บนแกนทฤษฎีการศึกษาและระเบียบวิธีวิจัย 4 เสาหลัก:

### 🎓 1.1 กรอบแนวคิด CT-S (Hurt et al., 2023)
* **CT as Input:** ผู้เรียนใช้ทักษะการคิดเชิงคำนวณ (Decomposition, Abstraction, Pattern Recognition, Algorithm) ในการตั้งสมมติฐานและวิเคราะห์ตัวแปร
* **Mediating Computational Tools:** การใช้เครื่องมือจำลอง (NetLogo, PhET, Python, Micro:bit) เป็นตัวกลางในการทดลอง *In Silico*
* **Science as Outcome:** มุ่งเน้นการให้เหตุผลเชิงกลไก (Mechanistic Reasoning) และความเข้าใจมโนทัศน์วิทยาศาสตร์เชิงลึก

### 🔬 1.2 กรอบอนุกรมวิธาน 4 มิติ (Weintrop et al., 2016)
1. **Data Practices:** รวบรวม จัดการ วิเคราะห์ และแสดงผลข้อมูลวิทยาศาสตร์ด้วยภาพ
2. **Modeling & Simulation:** สำรวจ สร้าง และทดสอบสมมติฐานผ่านตัวแบบจำลองคอมพิวเตอร์
3. **Computational Problem Solving:** แก้ปัญหาเชิงขั้นตอน พัฒนาโค้ด และตรวจแก้ข้อผิดพลาด (Debugging)
4. **Systems Thinking:** ทำความเข้าใจระบบที่ซับซ้อน ความสัมพันธ์ไม่เป็นเชิงเส้น และวงจรป้อนกลับ (Feedback Loops)

### 💡 1.3 กลไกการคิดเชิงนามธรรม (Oser & Standl, 2025; Qian & Choi, 2022)
* **Dual-Process of Abstraction:** ทำงานร่วมกันระหว่างการคัดกรองซ่อนรายละเอียด (Information Hiding/Filtering) กับการสร้างตัวแทนเชิงสัญลักษณ์ทั่วไป (Generalization/Re-representation)
* **3-Stage Scaffolding:** หยั่งรากเชิงรูปธรรม (Cognitive Grounding) $\rightarrow$ การถอดบริบทอย่างเป็นขั้น (Progressive Decontextualization) $\rightarrow$ การสะท้อนคิดอภิปัญญา (Metacognitive Modeling)

## 🎨 2. กฎเหล็กด้านทัศนศิลป์และสื่อสารสนเทศ (No Text-Wall Rule)

> [!IMPORTANT]
> **ห้ามมิให้มีหัวข้อเนื้อหาที่เป็นข้อความบรรยายพารากราฟยาวติดต่อกันโดยเด็ดขาด!**  
> ทุกหัวข้อย่อยที่มีเนื้อหา ต้องได้รับการแปลงหรือเสริมด้วยองค์ประกอบภาพอย่างน้อย 1 อย่างเสมอ:

1. **Inline Vector SVG Infographics:** 
   * ใช้จานสีระดับพรีเมียม (Slate `#0f172a`, Indigo `#1e3a8a`, Blue `#2563eb`, Emerald `#059669`, Violet `#7c3aed`, Amber `#d97706`)
   * มีมิติความลึกด้วย Drop Shadow Filter (`dx="0" dy="3" stdDeviation="4" flood-opacity="0.12"`)
   * รองรับ Responsive เต็มจอด้วย `viewBox="0 0 W H" width="100%" height="100%"`
   * ตัวอักษรใช้ฟอนต์ `'Sarabun', sans-serif` หรือ `'Inter', sans-serif` คมชัด ไม่แตก
2. **ANSI Standard Flowcharts:** 
   * มีสัญลักษณ์ Terminal, Process, Decision Diamond, ลูกศรบอกทิศทาง และ Feedback Loop ที่ชัดเจน
3. **Multi-Column Synthesis Tables:**
   * ตารางเปรียบเทียบมโนทัศน์ สาระสำคัญ และตัวอย่างข้ามสาขา (ฟิสิกส์, เคมี, ชีววิทยา, สิ่งแวดล้อม)
   * แสดงสิ่งที่คงไว้ (Kept Details) vs สิ่งที่ตัดทอนออก (Filtered Details)
4. **Self-Contained Python 3.11 Implementations:**
   * โค้ดวิทยาศาสตร์ที่รันได้จริง 100% ไม่มี Placeholder (`# ...`) พร้อมคอมเมนต์อธิบายจุดเชื่อมโยงกับ CT

## 📑 3. โครงสร้างสถาปัตยกรรมบทเรียน 6 แท็บ (The 6-Tab Standard)

ทุกไฟล์บทเรียน `lessons/week_XX.html` ต้องมีแท็บนำทางครบ 6 แท็บ:

```
[Tab 1: 🎯 ผลลัพธ์การเรียนรู้] -> WLOs 4 ด้าน (Knowledge, Skill, Ethics, Pedagogy) ตาม Bloom
[Tab 2: 📋 สาระสำคัญเชิงวิชาการ] -> เนื้อหาเข้มข้น + Infographics SVG ทุกหัวข้อ + ตาราง + โค้ด Python
[Tab 3: 🎓 กิจกรรมการสอน] -> Active Learning (บรรยาย 2 ชม. + ปฏิบัติ 2 ชม.) อิงงานวิจัย Wang/Hurt
[Tab 4: 📊 การวัดและประเมินผล] -> ตาราง Rubric 4 ระดับ (Listiaji 2026, Oser & Standl 2025)
[Tab 5: 📝 ข้อสอบวัดสมรรถนะ] -> HOTS Questions จากคลังข้อสอบ สสวท. 60 ข้อ พร้อมเฉลยและบทวิเคราะห์
[Tab 6: 📚 เอกสารอ้างอิง APA 7] -> บรรณานุกรมระดับชาติ/นานาชาติ ค้นผ่าน Consensus พร้อมลิงก์ DOI สด
```

## 🔍 4. ระเบียบวิธีสืบค้นวรรณกรรมและบรรณานุกรม (Literature Workflow)

1. **การสืบค้นข้อมูลปฐมภูมิ:**
   * เรียกใช้ MCP `consensus_search` สำหรับคำถามวิจัยเฉพาะด้าน (ดึงบทความ Q1 พร้อมค่า Citation, DOI และ Consensus AI Takeaway)
   * เชื่อมโยงกับคลังเอกสาร สสวท. และข้อสอบ 60 ข้อในเครื่องที่ `CS_Final/`
2. **การลงรายการอ้างอิงมาตรฐาน APA 7th Edition:**
   * นามสกุล, อักษรย่อชื่อ. (ปี). ชื่อบทความ. *ชื่อวารสาร (ตัวเอียง)*, *ฉบับที่*(เล่มที่), เลขหน้า. `https://doi.org/xxxx`
   * ภาษาไทย: ชื่อ นามสกุล. (ปี). *ชื่อหนังสือ/ตำรา*. สำนักพิมพ์.
