ผลลัพธ์การเรียนรู้ระดับสัปดาห์ (Weekly Learning Outcomes: WLOs)

ออกแบบตามกรอบอนุกรมวิธานของบลูมฉบับปรับปรุง (Revised Bloom's Taxonomy) บูรณาการหลักฐานเชิงประจักษ์ด้านการรับรู้ภาพและการลดภาระทางปัญญา (Cognitive Load Reduction) ในการออกแบบอัลกอริทึม (Andrzejewska & Stolińska, 2022; Julaihi & Bohari, 2026):

WLO 1: ด้านความรู้เชิงสัญลักษณ์

มาตรฐานสัญลักษณ์ผังงานและไวยากรณ์

ระบุและอธิบายสัญลักษณ์มาตรฐาน ANSI/ISO 5807 (Terminator, Process, Input/Output, Decision, Loop/Connector) และคำสงวนรหัสลำลอง (READ, COMPUTE, IF-ELSE, WHILE, PRINT) ได้อย่างถูกต้องแม่นยำ

WLO 2: ด้านการสร้างแบบจำลอง

การแปลงกระบวนการแล็บเป็นแบบจำลอง IPO

วิเคราะห์แยกแยะคู่มือปฏิบัติการวิทยาศาสตร์ (Laboratory Protocols) ให้อยู่ในรูปของ Input-Process-Output (IPO) พร้อมกำหนดเงื่อนไขทางเลือกและจุดสิ้นสุดวงรอบการทดลองซ้ำได้อย่างสมบูรณ์

WLO 3: ด้านทักษะการตรวจสอบความถูกต้อง

การตรวจสอบตรรกะและป้องกัน Infinite Loop

ตรวจสอบ ติดตามเส้นทางการไหล (Flow Tracing) และแก้ไขจุดผิดพลาดเชิงตรรกะ (Logical Bug Hunting) ป้องกันสภาวะลูปไม่รู้จบและทางแยกที่ไร้ป้ายกำกับเงื่อนไขในผังงานการทดลองวิทยาศาสตร์

WLO 4: ด้านการจัดการเรียนรู้วิทยาศาสตร์

การสร้างนั่งร้านทางปัญญา (Scaffolding)

ประยุกต์ใช้ Progressive Flowchart Scaffolding (Zhang et al., 2021) ในการออกแบบใบกิจกรรมเพื่อช่วยให้นักเรียนระดับมัธยมศึกษาสามารถวางแผนการทดลองโครงงานวิทยาศาสตร์ได้อย่างเป็นระบบ

หลักฐานเชิงประจักษ์ด้าน Eye-Tracking (Andrzejewska & Stolińska, 2022)

งานวิจัยด้วยเทคโนโลยีตรวจจับสายตา (Eye Movements) ยืนยันว่า ผังงานที่มีโครงสร้างชัดเจน (Structured Flowcharts) ช่วยลดเวลาในการทำความเข้าใจอัลกอริทึมลงอย่างมีนัยสำคัญ และเพิ่มความมั่นใจในความถูกต้องของผู้เรียนมากกว่าข้อความบรรยายหรือรหัสลำลองล้วน เนื่องจากสมองมนุษย์ประมวลผลทิศทางการไหลเชิงเรขาคณิต (Spatial Visual Processing) ได้เร็วกว่าการถอดรหัสข้อความแบบเชิงเส้น

สาระสำคัญเชิงวิชาการ: ไวยากรณ์ผังงานและรหัสลำลองในกระบวนการวิทยาศาสตร์

การเปลี่ยนจากแนวคิดเชิงนามธรรม (Abstraction) และขั้นตอนวิธี (Algorithm) ไปสู่การเขียนโปรแกรมคอมพิวเตอร์เพื่อควบคุมแล็บหรือจำลองแบบวิทยาศาสตร์ จำเป็นต้องอาศัย "เครื่องมือตัวแทนความคิด 2 รูปแบบ" (Dual Representation Models) ได้แก่ ผังงาน (Flowchart) ซึ่งเป็นตัวแทนเชิงทัศนภาพ (Visual Representation) และ รหัสลำลอง (Pseudocode) ซึ่งเป็นตัวแทนเชิงโครงสร้างข้อความ (Textual Structural Representation) (Nita & Kartikawati, 2020; Ghosh et al., 2023)

# =====================================================================
# โครงการ: ตัวแบบจำลองการประมวลผลผังงานและรหัสลำลองการทดลองวิทยาศาสตร์
# ผู้พัฒนา: ผู้ช่วยศาสตราจารย์ ดร.ชีวะ ทัศนา
# สังกัด: คณะวิทยาศาสตร์และเทคโนโลยี มหาวิทยาลัยราชภัฏรำไพพรรณี
# =====================================================================

from typing import Dict, Any, List

# ---------------------------------------------------------------------
# 1. SEQUENTIAL FLOWCHART SIMULATION: คำนวณความหนาแน่นและปริมาตรทรงกลม
# ---------------------------------------------------------------------
def simulate_sequential_density(mass_grams: float, radius_cm: float) -> Dict[str, float]:
    """
    แปลงผังงานแบบลำดับ (Sequential Flowchart) สำหรับการหาความหนาแน่นทรงกลม
    IPO: Input (mass, radius) -> Process (Volume = 4/3 pi r^3, D = M/V) -> Output (Density)
    """
    import math
    if radius_cm <= 0 or mass_grams <= 0:
        raise ValueError("ค่ามวลและรัศมีต้องมากกว่าศูนย์")
        
    volume = (4.0 / 3.0) * math.pi * (radius_cm ** 3)
    density = mass_grams / volume
    return {"mass": mass_grams, "volume": volume, "density": density}


# ---------------------------------------------------------------------
# 2. SELECTION FLOWCHART SIMULATION: การจำแนกสารเคมีด้วย Decision Tree
# ---------------------------------------------------------------------
def simulate_selection_biomolecule_test(iodine_blue: bool, biuret_purple: bool, benedict_red: bool) -> str:
    """
    แปลงผังงานแบบมีทางเลือก (Branching Flowchart) จำแนกสารชีวโมเลกุลในอาหาร
    """
    if iodine_blue:
        return "พบสารประเภท แป้ง (Starch)"
    elif biuret_purple:
        return "พบสารประเภท โปรตีน (Protein)"
    elif benedict_red:
        return "พบสารประเภท น้ำตาลรีดิวซ์ (Reducing Sugar)"
    else:
        return "ไม่พบสารชีวโมเลกุลหลักทั้ง 3 ชนิด (หรือความเข้มข้นต่ำกว่าเกณฑ์ตรวจวัด)"


# ---------------------------------------------------------------------
# 3. ITERATIVE FLOWCHART WITH TERMINATION SAFETY (ป้องกัน Infinite Loop)
# ---------------------------------------------------------------------
def simulate_titration_loop(v_acid: float = 20.0, c_base: float = 0.10, target_ph: float = 7.0, max_steps: int = 500) -> Dict[str, Any]:
    """
    แปลงผังงานการไทเทรต (ภาพที่ 4.3) พร้อมระบบป้องกัน Infinite Loop
    """
    v_base = 0.0
    current_ph = 1.0  # เริ่มต้นที่กรดแก่ pH 1
    step_count = 0
    history: List[Dict] = []
    
    while current_ph < target_ph:
        step_count += 1
        # Safety Check: ป้องกันข้อผิดพลาด Infinite Loop ในผังงาน
        if step_count > max_steps:
            raise TimeoutError("Infinite Loop Detected! ผังงานไม่มีเงื่อนไขหยุดที่รัดกุม")
            
        v_base += 0.2  # หยดสารทีละ 0.2 mL
        # จำลองการเปลี่ยนแปลงค่า pH เมื่อใกล้จุดสมมูล
        current_ph = 1.0 + (6.0 * (v_base / 20.0)) if v_base < 20.0 else 7.0 + (5.0 * ((v_base - 20.0) / 5.0))
        history.append({"step": step_count, "v_base": round(v_base, 2), "pH": round(current_ph, 2)})
        
    # เมื่อหลุดลูป (จุดยุติ): คำนวณความเข้มข้นกรด
    c_acid = (c_base * v_base) / v_acid
    return {
        "total_steps": step_count,
        "v_base_used": round(v_base, 2),
        "final_ph": round(current_ph, 2),
        "calculated_c_acid": round(c_acid, 4),
        "status": "Titration Completed Successfully"
    }


if __name__ == "__main__":
    print("=== [1] ทดสอบผังงานแบบลำดับ (Sequential Density Flowchart) ===")
    res_seq = simulate_sequential_density(mass_grams=45.5, radius_cm=1.8)
    print(f"มวล: {res_seq['mass']} g, ปริมาตร: {res_seq['volume']:.2f} cm³, ความหนาแน่น: {res_seq['density']:.3f} g/cm³\n")

    print("=== [2] ทดสอบผังงานแบบมีทางเลือก (Selection Decision Tree) ===")
    sample_result = simulate_selection_biomolecule_test(iodine_blue=False, biuret_purple=True, benedict_red=False)
    print(f"ผลการวินิจฉัยสารละลายตัวอย่าง: {sample_result}\n")

    print("=== [3] ทดสอบผังงานแบบทำซ้ำ (Iterative Titration Loop) ===")
    res_titrate = simulate_titration_loop(v_acid=20.0, c_base=0.10)
    print(f"สิ้นสุดการไทเทรตใน {res_titrate['total_steps']} รอบการหยด")
    print(f"ปริมาตรเบสที่ใช้ ณ จุดยุติ: {res_titrate['v_base_used']} mL (pH = {res_titrate['final_ph']})")
    print(f"ความเข้มข้นของกรดไฮโดรคลอริกตัวอย่าง: {res_titrate['calculated_c_acid']} M")

    อาจารย์บรรยายเชิงลึกเกี่ยวกับสัญลักษณ์มาตรฐาน 5 ตัวหลัก, กฎการเขียนรหัสลำลองที่กระชับ ไม่ขึ้นกับภาษาโปรแกรมใดภาษาหนึ่ง (Language-Agnostic), และการใช้ Eye-Tracking Evidence (Andrzejewska & Stolińska, 2022) อธิบายเหตุผลที่ผังงานช่วยลดภาระทางปัญญาในการทำความเข้าใจการทดลอง

  3. กิจกรรมย่อย "Flowchart Bug Hunt" (30 นาที):

    แจกใบงานผังงานวิทยาศาสตร์ที่มี "บั๊กที่พบบ่อย 4 แบบ" ให้นักศึกษาช่วยกันค้นหาและวงกลมแก้ไข:

    • 1. การใช้สัญลักษณ์ผิดประเภท (เช่น นำสี่เหลี่ยมผืนผ้า Process มาใส่การรับค่า Input)
    • 2. สี่เหลี่ยมขนมเปียกปูน (Decision) ที่มีเส้นทางออกเพียงเส้นเดียว หรือลืมระบุ Label ใช่/ไม่ใช่ (Yes/No)
    • 3. สภาวะลูปไม่รู้จบ (Infinite Loop) ที่ไม่มีขั้นตอนปรับค่าตัวแปรเงื่อนไข
    • 4. สภาวะเส้นลูกศรไม่มีหัวลูกศร หรือทิศทางการไหลย้อนแย้ง (Dangling Flowlines)
  4. ขั้นสรุปเชื่อมโยง (Elaboration - 15 นาที):

    สรุปข้อค้นพบ และเตรียมความพร้อมสู่การแปลงการทดลองแล็บจริงเป็นผังงานในชั่วโมงปฏิบัติการ

ชั่วโมงที่ 3-4: ปฏิบัติการแปลงคู่มือแล็บสู่ผังงาน และกิจกรรม Gallery Walk 120 นาที
  1. กิจกรรมกลุ่มย่อย (Group Workshop - 60 นาที): "Scientific Protocol to Flowchart & Pseudocode"

    แบ่งกลุ่มนักศึกษา 4-5 คน เลือกหัวข้อการทดลองวิทยาศาสตร์ระดับมัธยม 1 การทดลอง (เช่น 1. การสกัดคลอโรฟิลล์จากใบไม้, 2. การหาอัตราส่วนโมลของปฏิกิริยาเคมี, 3. การหาค่าความเร่งโน้มถ่วง \(g\) ด้วยการตกอิสระ) จากนั้น:

    • ภาระงานที่ 1: วาดผังงาน (Flowchart) ตามมาตรฐาน ANSI/ISO 5807 ลงบนกระดาษ Flipchart ขนาดใหญ่ เน้นการใช้สีแยกประเภทสัญลักษณ์
    • ภาระงานที่ 2: เขียนรหัสลำลอง (Pseudocode) เทียบเคียงคู่ขนานทีละบล็อกคำสั่ง
    • ภาระงานที่ 3: ระบุตัวแปร Input, Output, เงื่อนไขทางเลือก และการวนรอบการทดลองซ้ำ 3 ซ้ำ
  2. กิจกรรม "Gallery Walk & Peer Flow Execution" (40 นาที):

    แต่ละกลุ่มนำ Flipchart ติดแสดงรอบห้องเรียน สมาชิกแต่ละกลุ่มหมุนเวียนไปตรวจผลงานของเพื่อน โดยใช้ปากกาไฮไลต์ลากเส้นตาม Flowline หากพบจุดที่ขั้นตอนกำกวม สัญลักษณ์ผิด หรือเกิด Infinite Loop ให้แปะ Post-it สะท้อนคิดเชิงสร้างสรรค์

  3. การสะท้อนคิดอภิปัญญาและสรุปผล (AAR & Wrap-up - 20 นาที):

    อาจารย์ให้ Feedback สรุปจุดแข็ง-จุดพัฒนาของแต่ละกลุ่ม พร้อมเชื่อมโยงว่าในสัปดาห์ที่ 5 เราจะนำผังงานและรหัสลำลองเหล่านี้ไปเขียนเป็นโค้ดจริงในภาษา Python/Scratch

เกณฑ์การวัดและประเมินผลการเรียนรู้ (Authentic Rubrics Matrix)

เกณฑ์การประเมินการออกแบบผังงานและรหัสลำลองวิทยาศาสตร์ 4 ระดับคุณภาพ พัฒนาตามเกณฑ์ประเมินสมรรถนะการสร้างแบบจำลองขั้นตอนวิธี (Zhang et al., 2021; Listiaji et al., 2026):

มิติการประเมิน ดีมาก (4 คะแนน) ดี (3 คะแนน) พอใช้ (2 คะแนน) ปรับปรุง (1 คะแนน)
1. ความถูกต้องของสัญลักษณ์ผังงาน (Symbolic Precision) ใช้สัญลักษณ์มาตรฐาน ANSI/ISO 5807 ถูกต้องสมบูรณ์ 100% ทุกรูปทรง ทิศทางหัวลูกศรชัดเจน มีจุดเริ่มต้นและสิ้นสุดเพียงจุดเดียว ใช้สัญลักษณ์ถูกต้องเป็นส่วนใหญ่ มีข้อผิดพลาดเล็กน้อยที่ไม่ส่งผลต่อความหมาย เช่น รูปทรงด้านขนานเอียงไม่ชัดเจน สับสนการใช้สัญลักษณ์บางประเภท เช่น ใช้สี่เหลี่ยมผืนผ้าแทนการรับค่า Input หรือลืมใส่ลูกศรบอกทิศทาง ใช้สัญลักษณ์ผิดประเภทเป็นส่วนใหญ่ ไม่เป็นไปตามมาตรฐานสากล
2. ความสมบูรณ์ของตรรกะและเงื่อนไข (Logical Correctness) การตัดสินใจ (Decision) มีเส้นทางออกครบถ้วนพร้อมระบุเงื่อนไข ใช่/ไม่ใช่ ชัดเจน มีเงื่อนไขการหยุดลูปที่รัดกุม ปราศจาก Infinite Loop 100% ตรรกะถูกต้องเป็นส่วนใหญ่ การวนซ้ำมีจุดหยุดที่ชัดเจน แต่อาจขาดป้ายกำกับเงื่อนไขในบางเส้นทาง มีข้อผิดพลาดเชิงตรรกะ เช่น เงื่อนไขคลุมเครือ หรือมีความเสี่ยงที่จะเกิด Infinite Loop ในบางกรณี ตรรกะผังงานผิดพลาด เกิดทางตัน (Deadlock) หรือเกิดลูปไม่รู้จบอย่างชัดเจน
3. ความแม่นยำของรหัสลำลอง (Pseudocode Quality) เขียนรหัสลำลองสอดคล้องกับผังงานแบบ 1 ต่อ 1 ใช้คำสงวนมาตรฐาน (INPUT, COMPUTE, IF-ELSE, WHILE) มีการย่อหน้า (Indentation) สวยงาม รหัสลำลองสอดคล้องกับผังงานดี โครงสร้างคำสั่งถูกต้อง แต่อาจขาดการย่อหน้าในบางจุด รหัสลำลองเขียนเป็นข้อความบรรยายพารากราฟยาว ไม่ได้แยกเป็นบรรทัดคำสั่งโครงสร้างคอมพิวเตอร์ รหัสลำลองไม่สอดคล้องกับผังงาน และไม่สื่อถึงกระบวนการเชิงคำนวณ
4. การบูรณาการบริบทวิทยาศาสตร์ (Science Pedagogical Rigor) ผังงานถ่ายทอดกระบวนการทดลองวิทยาศาสตร์ได้อย่างลึกซึ้ง ครอบคลุมทั้งตัวแปรต้น ตัวแปรตาม และการควบคุมความคลาดเคลื่อนในการทดลอง ผังงานแสดงขั้นตอนการทดลองได้ถูกต้องครบถ้วนตามคู่มือแล็บ ผังงานข้ามขั้นตอนสำคัญของการทดลองทางวิทยาศาสตร์ เช่น ลืมขั้นตอนการล้างอุปกรณ์หรือการควบคุมอุณหภูมิ เนื้อหาในผังงานไม่ถูกต้องตามหลักการทดลองทางวิทยาศาสตร์

ข้อสอบวัดสมรรถนะการคิดขั้นสูง (Higher-Order Thinking Skills: HOTS)

ข้อสอบวัดสมรรถนะคัดสรรจาก คลังข้อสอบมาตรฐานวิทยาการคำนวณ สสวท. (60 ข้อ) ที่มุ่งเน้นการตรวจแก้ข้อผิดพลาดเชิงตรรกะ (Debugging) และการสร้างแบบจำลองผังงานในงานวิทยาศาสตร์:

ข้อที่ 1: การวิเคราะห์ข้อผิดพลาดในผังงานการทดลองวิทยาศาสตร์ (HOTS: Analyzing & Debugging)

สสวท. หมวด Flowchart-Debugging

สถานการณ์: นักเรียนเขียนผังงานเพื่อควบคุมระบบเซนเซอร์วัดอุณหภูมิในการทดลองต้มน้ำเดือด โดยมีลำดับขั้นตอนดังนี้:

[START] → [อ่านค่าอุณหภูมิ T] → <T ≥ 100°C?>
  • ถ้า YES → [บันทึกเวลาจุดเดือด] → [END]
  • ถ้า NO → [ส่งเสียงเตือนบี๊บ] → <T ≥ 100°C?> (วนกลับเข้าเงื่อนไขเดิมทันที โดยไม่ได้อ่านค่า T ใหม่)

หากนำผังงานนี้ไปเขียนโปรแกรมควบคุมอุปกรณ์จริงในห้องแล็บ จะเกิดข้อผิดพลาด (Bug) ใดขึ้น?

ก. เกิด Syntax Error เพราะไม่สามารถใช้ตัวแปร T ได้
ข. เกิดสภาวะลูปไม่รู้จบ (Infinite Loop) และส่งเสียงเตือนไม่หยุด เพราะเมื่ออุณหภูมิยังไม่ถึง 100°C ผังงานวนกลับไปตรวจตัวแปรเดิมโดยไม่มีคำสั่ง [อ่านค่าอุณหภูมิ T ใหม่จากเซนเซอร์]
ค. น้ำจะไม่เดือด เพราะโปรแกรมทำให้ฮีตเตอร์ตัดการทำงาน
ง. ไม่เกิดข้อผิดพลาดใดๆ โปรแกรมทำงานได้ถูกต้องสมบูรณ์
เฉลย: ข. เกิดสภาวะลูปไม่รู้จบ (Infinite Loop)
บทวิเคราะห์เชิงวิทยาการคำนวณ: โครงสร้างลูปที่ดี (Iterative Structure) ต้องมีคำสั่งปรับปรุงค่าตัวแปรควบคุมเงื่อนไข (Loop Update Step) ในแต่ละรอบ ในกรณีนี้เมื่อค่า \(T < 100\) โปรแกรมต้องวนกลับไปที่กล่องรับค่า [อ่านค่าอุณหภูมิ T ใหม่จากเซนเซอร์] หากวนกลับเข้ากล่อง Decision ทันที ค่า \(T\) จะคงที่ตลอดกาล ส่งผลให้เงื่อนไขเป็นเท็จไม่สิ้นสุด (Andrzejewska & Stolińska, 2022)

ข้อที่ 2: การแปลงรหัสลำลองการทดสอบสารชีวโมเลกุลเป็นผังงาน (HOTS: Applying & Translating)

สสวท. หมวด Pseudocode-Mapping

สถานการณ์: พิจารณารหัสลำลอง (Pseudocode) ของการทดสอบสารละลายตัวอย่างต่อไปนี้:

INPUT sample_solution
ADD 3 drops of Iodine
IF color == "Dark Blue" THEN
    DISPLAY "Starch Positive"
ELSE
    ADD Biuret Reagent
    IF color == "Purple" THEN
        DISPLAY "Protein Positive"
    ELSE
        DISPLAY "Unknown Sample"
    ENDIF
ENDIF
DISPLAY "Test Completed"

จากการวิเคราะห์รหัสลำลองข้างต้น เมื่อนำไปวาดเป็นผังงานมาตรฐาน (ANSI Flowchart) จะต้องใช้ สัญลักษณ์สี่เหลี่ยมขนมเปียกปูน (Decision) และ สัญลักษณ์สี่เหลี่ยมด้านขนาน (Input/Output) รวมกันอย่างน้อยกี่รูป?

ก. Decision 1 รูป และ Input/Output 2 รูป (รวม 3 รูป)
ข. Decision 2 รูป และ Input/Output 5 รูป (รวม 7 รูป)
ค. Decision 3 รูป และ Input/Output 3 รูป (รวม 6 รูป)
ง. Decision 2 รูป และ Input/Output 2 รูป (รวม 4 รูป)
เฉลย: ข. Decision 2 รูป และ Input/Output 5 รูป (รวม 7 รูป)
บทวิเคราะห์เชิงโครงสร้าง:
1. Decision (สี่เหลี่ยมขนมเปียกปูน): มีเงื่อนไขซ้อนกัน (Nested If-Else) 2 ตำแหน่ง คือ (1) color == "Dark Blue"? และ (2) color == "Purple"? = รวม 2 รูป
2. Input/Output (สี่เหลี่ยมด้านขนาน): มีการรับค่าและแสดงผล 5 จุด ได้แก่ INPUT sample_solution (1 จุด), DISPLAY "Starch Positive" (1 จุด), DISPLAY "Protein Positive" (1 จุด), DISPLAY "Unknown Sample" (1 จุด), และ DISPLAY "Test Completed" (1 จุด) = รวม 5 รูป
3. ผลรวมสัญลักษณ์ทั้งสองชนิด = \(2 + 5 = 7\) รูป สะท้อนความเข้าใจเรื่องการจับคู่ระหว่างคำสงวนของรหัสลำลองกับสัญลักษณ์ผังงานอย่างแม่นยำ
