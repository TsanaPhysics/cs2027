ผลลัพธ์การเรียนรู้การสอบกลางภาค (Midterm Learning Outcomes: WLOs)

การสอบกลางภาคประมวลผลสัมฤทธิ์ทางการเรียนสัปดาห์ที่ 1 - 7 เพื่อวัดสมรรถนะ 4 มิติเชิงบูรณาการวิทยาการคำนวณในการสอนวิทยาศาสตร์:

WLO 1: ความรอบรู้ในแนวคิดเชิงคำนวณ (Foundational CT Mastery)

แสดงออกถึงความรู้ความเข้าใจอย่างลึกซึ้งใน 4 เสาหลักของแนวคิดเชิงคำนวณ (Decomposition, Pattern Recognition, Abstraction, Algorithm Design) สามารถแยกแยะความแตกต่างและเชื่อมโยงสู่ปรากฏการณ์และการทดลองทางวิทยาศาสตร์ได้อย่างถูกต้อง 100%

WLO 2: การออกแบบขั้นตอนวิธีและผังงาน (Algorithmic & Modeling Proficiency)

สามารถวิเคราะห์ปัญหาการทดลองทางวิทยาศาสตร์ แปลงเป็นรหัสลำลอง (Pseudocode) และผังงานมาตรฐานสากล ANSI/ISO 5807 (Flowchart) ครบทั้ง 3 โครงสร้างควบคุม (Sequence, Selection, Iteration) ได้อย่างเป็นระบบและปราศจากข้อผิดพลาดเชิงตรรกะ

WLO 3: ทักษะการเขียนโปรแกรมสดและการดีบัก (Live Coding & Debugging Skill)

สามารถเขียนโค้ดภาษา Scratch หรือ Python 3.11 เพื่อแก้โจทย์วิทยาศาสตร์สดภายใต้เวลาจำกัด ประยุกต์ใช้ตัวแปร เงื่อนไข การวนซ้ำ ฟังก์ชัน และโครงสร้างข้อมูลลิสต์/อาร์เรย์ พร้อมทั้งตรวจหาและแก้ไขข้อผิดพลาด (Syntax, Runtime, Logic Error) ได้อย่างรวดเร็วและแม่นยำ

WLO 4: จริยธรรมทางวิชาการและการประเมิน (Academic Integrity & Evaluation Ethics)

ปฏิบัติตามกฎระเบียบการสอบอย่างเคร่งครัด ยึดมั่นในความซื่อสัตย์สุจริตทางวิชาการ (Academic Integrity) ไม่ทุจริต ไม่คัดลอกผลงาน (Anti-Plagiarism) และตระหนักถึงจรรยาบรรณวิชาชีพครูในการวัดและประเมินผลทางการศึกษาอย่างเป็นธรรม

การประเมินเพื่อตัดสินผลการเรียน (Summative Assessment): การสอบกลางภาคคิดเป็นน้ำหนัก 20% ของคะแนนรวมทั้งรายวิชา ประเมินตรงตาม CLO1 (แนวคิดเชิงคำนวณ), CLO2 (การเขียนโปรแกรมจำลองแบบ), และ CLO3 (จริยธรรมและความรับผิดชอบ)

ตัวแบบโจทย์สอบปฏิบัติการแล็บสด Python 3.11: โปรแกรมวิเคราะห์ข้อมูลฟิสิกส์และการตรวจจับ Outlier

ตัวอย่างโครงร่างโจทย์สอบปฏิบัติการแล็บสด พร้อมระบบ Automated Test Suite สำหรับให้กรรมการประเมินและนักศึกษาใช้ทดสอบความถูกต้องทันที: 

# ==============================================================================
# ข้อสอบปฏิบัติการกลางภาค (Midterm Practical Lab Exam) - วิชา 4124941
# โจทย์: จงเขียนฟังก์ชันวิเคราะห์อัตราเร็วเฉลี่ยของการทดลองการเคลื่อนที่แนวตรง
# พร้อมทั้งตัดข้อมูล Outlier และมีระบบป้องกันกรณีชุดข้อมูลว่าง (Empty Dataset)
# ==============================================================================
from typing import List, Dict

def process_motion_lab_data(time_intervals: List[float], distances: List[float]) -> Dict[str, float]:
    """
    คำนวณอัตราเร็วเฉลี่ย v = distance / time ในแต่ละช่วง แล้วหาค่าเฉลี่ยรวม
    
    ข้อกำหนด:
    1. ตรวจสอบความยาวของ time_intervals และ distances ต้องเท่ากันและไม่เป็น 0
    2. หากมีค่าเวลา t <= 0 ให้ยกเว้นค่าจุดนั้น (ป้องกัน ZeroDivisionError)
    3. คำนวณความเร็วเฉลี่ยรวม (Total Mean Velocity)
    """
    if not time_intervals or not distances:
        raise ValueError("ชุดข้อมูลเวลาและระยะทางต้องไม่ว่างเปล่า")
    if len(time_intervals) != len(distances):
        raise ValueError("จำนวนข้อมูลเวลาและระยะทางต้องมีขนาดเท่ากัน")
        
    velocities: List[float] = []
    
    # วนลูปคำนวณความเร็วในแต่ละช่วง
    for t, s in zip(time_intervals, distances):
        if t > 0 and s >= 0:
            velocities.append(s / t)
            
    if not velocities:
        raise ValueError("ไม่มีข้อมูลที่สามารถนำมาคำนวณความเร็วได้")
        
    mean_v = sum(velocities) / len(velocities)
    
    return {
        "valid_points": float(len(velocities)),
        "mean_velocity": round(mean_v, 3),
        "max_velocity": round(max(velocities), 3),
        "min_velocity": round(min(velocities), 3)
    }

# ------------------------------------------------------------------------------
# Automated Grading Test Suite (ชุดทดสอบให้คะแนนอัตโนมัติ)
# ------------------------------------------------------------------------------
def verify_student_submission():
    print("=" * 60)
    print("🧪 กำลังตรวจให้คะแนนข้อสอบปฏิบัติการกลางภาค (Automated Grading)...")
    print("=" * 60)
    
    # Test Case 1: ข้อมูลปกติ 4 ช่วงเวลา
    times = [1.0, 2.0, 1.0, 2.0]
    dists = [10.0, 20.0, 15.0, 30.0]  # v = [10.0, 10.0, 15.0, 15.0] -> mean = 12.5
    res1 = process_motion_lab_data(times, dists)
    assert res1["mean_velocity"] == 12.5, f"Test 1 ล้มเหลว! ได้ {res1['mean_velocity']}"
    print("✓ Test Case 1 Passed: คำนวณความเร็วเฉลี่ยข้อมูลปกติถูกต้อง (100/100)")
    
    # Test Case 2: ตรวจสอบการจัดการเวลา t = 0 (Defensive Guard)
    times_with_zero = [1.0, 0.0, 2.0]
    dists_with_zero = [10.0, 5.0, 20.0]
    res2 = process_motion_lab_data(times_with_zero, dists_with_zero)
    assert res2["valid_points"] == 2.0, "Test 2 ล้มเหลว! โปรแกรมไม่ละเว้นจุดที่เวลาเป็น 0"
    print("✓ Test Case 2 Passed: ละเว้นจุดเวลา t=0 ป้องกัน Crash สำเร็จ (100/100)")
    
    print("-" * 60)
    print("🏆 ยินดีด้วย! โค้ดของท่านผ่านการทดสอบครบทุกกรณี ได้คะแนนเต็ม 5.0 คะแนน")

if __name__ == "__main__":
    verify_student_submission()

เกณฑ์รูบริกส์การประเมินผลกลางภาคเพื่อตัดสินผลการเรียน (Summative Assessment Rubrics) จำแนก 4 ระดับคุณภาพ:

มิติสมรรถนะที่ประเมิน ดีเยี่ยม (4 คะแนน) ดี (3 คะแนน) พอใช้ (2 คะแนน) ปรับปรุง (1 คะแนน)
1. ความเข้าใจแนวคิดเชิงคำนวณ (CT Comprehension) วิเคราะห์และประยุกต์ใช้ 4 เสาหลัก CT ในการแก้ปัญหาโจทย์วิทยาศาสตร์ได้อย่างแม่นยำ สมบูรณ์ ปราศจากข้อคลาดเคลื่อน อธิบายและเชื่อมโยงเสาหลัก CT ได้ถูกต้องส่วนใหญ่ มีเหตุผลทางวิทยาศาสตร์รองรับชัดเจน ระบุเสาหลัก CT ได้ถูกต้องบางส่วน แต่ยังสับสนระหว่าง Abstraction และ Decomposition ในบางสถานการณ์ ไม่เข้าใจความหมายของเสาหลัก CT และไม่สามารถเชื่อมโยงกับการสอนวิทยาศาสตร์ได้
2. การออกแบบผังงานและรหัสลำลอง (Flowchart & Pseudocode) ใช้สัญลักษณ์มาตรฐาน ANSI/ISO 5807 ถูกต้อง 100% โครงสร้างควบคุมชัดเจน ลำดับขั้นตอนเป็นตรรกะที่รันได้จริง ใช้สัญลักษณ์ผังงานถูกต้องส่วนใหญ่ ทิศทางลูกศรชัดเจน มีรหัสลำลองที่อ่านเข้าใจง่าย มีข้อผิดพลาดเรื่องสัญลักษณ์ผังงาน เช่น ใช้สี่เหลี่ยมผืนผ้าแทนข้าวหลามตัด หรือลูกศรไม่มีหัว ไม่สามารถเขียนผังงานหรือรหัสลำลองได้ โครงสร้างสับสนและไม่เป็นขั้นตอน
3. สมรรถนะการเขียนโค้ดและดีบัก (Coding & Debugging) เขียนโค้ดแก้โจทย์แล็บได้ถูกต้อง 100% ผ่านทุก Test Case มี Defensive Guard และแก้บั๊กโจทย์ที่ 2 ได้อย่างสมบูรณ์ เขียนโค้ดแก้ปัญหาได้ถูกต้องผ่าน Normal Cases แต่ตกหล่น Boundary Cases บางข้อ แก้บั๊กได้ส่วนใหญ่ โค้ดทำงานได้บางส่วน มีข้อผิดพลาด Runtime หรือ Logic Error ที่แก้ไม่เสร็จทันเวลา โค้ดมี Syntax Error ไม่สามารถรันโปรแกรมได้ และไม่สามารถหาจุดผิดพลาดของบั๊กได้
4. จริยธรรมและความเที่ยงตรง (Academic Integrity) ปฏิบัติตามกฎการสอบอย่างเคร่งครัด 100% โค้ดเป็นผลงานที่คิดขึ้นเอง ไม่มีการคัดลอกหรือใช้เครื่องมือต้องห้าม ปฏิบัติตามกฎการสอบอย่างเรียบร้อย มีความซื่อสัตย์สุจริตในการสอบ ต้องได้รับการตักเตือนเรื่องการปฏิบัติตามระเบียบข้อบังคับการสอบบางประการ พบพฤติกรรมส่อไปในทางทุจริต หรือคัดลอกโค้ดผู้อื่น (ปรับตกทันทีตามระเบียบมหาวิทยาลัย)
มาตรการทางวินัยด้านความซื่อสัตย์ทางวิชาการ: หากตรวจพบการทุจริตในการสอบ (เช่น การเปิด AI Chatbot ภายนอก, การแอบดูหน้าจอ, การส่งโค้ดให้ผู้อื่น) จะได้รับการปรับคะแนนเป็น 0 คะแนนในการสอบกลางภาคทันที และส่งเรื่องพิจารณาตามข้อบังคับมหาวิทยาลัยราชภัฏรำไพพรรณี

ข้อสอบจำลองวัดสมรรถนะขั้นสูง (HOTS Simulation Exam Bank)

ตัวอย่างข้อสอบวัดสมรรถนะขั้นสูงเชิงการคิดคำนวณตามมาตรฐาน สสวท. สำหรับฝึกซ้อมและเตรียมตัวก่อนการสอบกลางภาค:

ข้อที่ 1 (ระดับการวิเคราะห์และสังเคราะห์ - Analyzing & Designing):
ครูวิทยาศาสตร์ต้องการให้นักเรียนทำการทดลองหาอัตราเร็วเสียงในอากาศโดยใช้หลอดเรโซแนนซ์ (Resonance Tube) โดยบันทึกตำแหน่งเรโซแนนซ์ครั้งที่ 1 ($L_1$) และครั้งที่ 2 ($L_2$) เพื่อคำนวณความยาวคลื่น $\lambda = 2(L_2 - L_1)$ แล้วนำไปหาอัตราเร็วเสียง $v = f\lambda$ (เมื่อ $f$ คือความถี่ของส้อมเสียง)
หากต้องการเขียน ผังงาน (Flowchart) เพื่อควบคุมโปรแกรมให้รับค่า $L_1$ และ $L_2$ จากผู้ใช้ โดยมีเงื่อนไขตรวจสอบว่า $L_2$ ต้องมากกว่า $L_1$ เสมอ หากผู้ใช้ป้อนผิดให้แจ้งเตือนและวนกลับไปรับค่าใหม่ ข้อใดออกแบบสัญลักษณ์และขั้นตอนวิธีได้ถูกต้องตามมาตรฐาน ANSI/ISO 5807?
  • ก. ใช้รูปสี่เหลี่ยมผืนผ้า (Process) ในการตรวจสอบเงื่อนไข $L_2 > L_1$ แล้วโยงเส้นตรงไปยังจุดสิ้นสุด
  • ข. ใช้รูปสี่เหลี่ยมด้านขนาน (Input/Output) รับค่า $L_1, L_2$ จากนั้นใช้รูปสี่เหลี่ยมข้าวหลามตัด (Decision) ตรวจสอบเงื่อนไข $L_2 > L_1$ ถ้า "ไม่ใช่ (False)" ให้ส่งข้อความแจ้งเตือนทางรูปสี่เหลี่ยมด้านขนานแล้วลากเส้นวนลูปกลับไปรับค่าใหม่ ถ้า "ใช่ (True)" ให้เข้าสู่รูปสี่เหลี่ยมผืนผ้า (Process) เพื่อคำนวณสูตร
  • ค. ใช้รูปวงรี (Terminator) ตรวจสอบเงื่อนไขการคำนวณ และหยุดการทำงานทันทีหาก $L_1 \ge L_2$ โดยไม่ต้องให้ผู้ใช้ป้อนใหม่
  • ง. ใช้รูปหกเหลี่ยม (Preparation) เพื่อกำหนดให้ค่า $L_2$ เท่ากับ $2L_1$ เสมอโดยไม่ต้องรับค่าจากผู้ใช้
เฉลยข้อ ข. ถูกต้อง!
การวิเคราะห์ตามมาตรฐานสากล ANSI/ISO 5807:
  • การรับค่า $L_1, L_2$ จากคีย์บอร์ด ต้องใช้สัญลักษณ์ สี่เหลี่ยมด้านขนาน (Parallelogram) ซึ่งเป็นสัญลักษณ์ Input/Output มาตรฐาน
  • การตรวจสอบเงื่อนไขทางวิทยาศาสตร์ ($L_2 > L_1$) เพื่อยืนยันว่าเรโซแนนซ์ครั้งที่สองต้องยาวกว่าครั้งแรก ต้องใช้ สี่เหลี่ยมข้าวหลามตัด (Diamond - Decision)
  • หากเงื่อนไขเป็นเท็จ (ป้อน $L_2 \le L_1$) เส้นทาง Flowline ต้องชี้กลับไปยังขั้นตอนรับค่า (Looping Validation) เพื่อเปิดโอกาสให้ผู้ใช้แก้ไขข้อมูล
  • เมื่อเงื่อนไขเป็นจริง จึงเข้าสู่ สี่เหลี่ยมผืนผ้า (Rectangle - Process) เพื่อคำนวณ $v = 2f(L_2 - L_1)$
ข้อที่ 2 (ระดับการประเมินค่าและการดีบัก - Evaluating & Debugging):
นักศึกษาเขียนฟังก์ชัน Python เพื่อจำลองการถ่ายทอดลักษณะทางพันธุกรรมตามกฎของเมนเดล ในการผสมระหว่างถั่วลันเตาต้นสูงพันธุ์ทาง ($Tt \times Tt$) เพื่อหาอัตราส่วนของฟีโนไทป์ (ต้นสูง : ต้นเตี้ย) จากการสุ่มตัวอย่าง 1,000 ต้น โดยเขียนโค้ดดังนี้: 
import random

def simulate_mendelian_cross(trials=1000):
    tall_count = 0
    short_count = 0
    for i in range(trials):
        allele1 = random.choice(['T', 't'])
        allele2 = random.choice(['T', 't'])
        genotype = allele1 + allele2
        # บรรทัดตรวจสอบฟีโนไทป์
        if genotype == 'TT' and genotype == 'Tt':
            tall_count += 1
        else:
            short_count += 1
    return tall_count, short_count

tall, short = simulate_mendelian_cross(1000)
print(f"ต้นสูง: {tall}, ต้นเตี้ย: {short}")
เมื่อรันโปรแกรมนี้ ผลลัพธ์กลับแสดงค่า ต้นสูง: 0, ต้นเตี้ย: 1000 ทุกครั้ง ข้อใดชี้จุดบกพร่องของ Logic Error และวิธีแก้ไขได้อย่างถูกต้องที่สุด?
  • ก. ฟังก์ชัน random.choice สุ่มได้แต่ตัวอักษร 't' ตัวพิมพ์เล็ก ต้องเปลี่ยนเป็น random.randint(1, 2)
  • ข. ลูป range(trials) วนซ้ำไม่ถึง 1,000 รอบ ต้องแก้เป็น range(1, trials + 1)
  • ค. การใช้ตัวดำเนินการตรรกะ and ในเงื่อนไข genotype == 'TT' and genotype == 'Tt' เป็นไปไม่ได้ในทางตรรกศาสตร์ (ตัวแปรเดียวไม่สามารถเท่ากับ 2 ข้อความพร้อมกันได้) ทำให้เงื่อนไขเป็น False เสมอ ต้องแก้ไขเป็น 'T' in genotype หรือ genotype in ['TT', 'Tt', 'tT']
  • ง. ตัวแปร tall_count ไม่ได้ประกาศเป็น Global Variable ทำให้ค่าไม่เพิ่มขึ้น
เฉลยข้อ ค. ถูกต้อง!
การวิเคราะห์เชิงลึก:
  • นี่คือข้อผิดพลาด Logic Error ขั้นคลาสสิก: เงื่อนไข genotype == 'TT' and genotype == 'Tt' กำหนดให้สตริง genotype ต้องเท่ากับทั้ง "TT" และ "Tt" พร้อมกัน ซึ่งในระบบตรรกะบูลีนจะประเมินค่าได้เป็น เท็จ (False) เสมอ 100%
  • ส่งผลให้โปรแกรมกระโดดไปทำงานในบล็อก else ตลอดเวลา ทำให้ short_count เพิ่มขึ้นจนครบ 1,000 ส่วน tall_count ยังคงเป็น 0
  • นอกจากนี้ เมื่อสุ่ม allele1 และ allele2 จีโนไทป์แบบพันธุ์ทางอาจเกิดขึ้นได้ทั้ง 'Tt' และ 'tT' ดังนั้นวิธีเขียนที่ถูกต้องตามหลักวิทยาศาสตร์และสั้นกระชับที่สุดคือ if 'T' in genotype: (เพราะยีน T เป็นยีนเด่น หากมี T เพียงตัวเดียวก็จะเป็นต้นสูงทันทีตามกฎของเมนเดล)
