WLO 2: การจัดการข้อมูลอาร์เรย์/ลิสต์ (Data Manipulation Skill)

WLO 3: ทักษะการประมวลผลและการจำลอง (Computational Modeling)

พัฒนาโปรแกรมด้วย Scratch (Custom My Blocks & Lists) และ Python 3.11 เพื่อคำนวณสถิติพื้นฐาน ($\sum$, ค่าเฉลี่ยเลขคณิต $\bar{x}$, ค่าสูงสุด-ต่ำสุด, การกรอง Outlier) และจำลองปรากฏการณ์พลวัตทางวิทยาศาสตร์ เช่น การสลายตัวของสารกัมมันตรังสี (Half-Life Decay) หรือการแพร่ของสารเคมีได้อย่างมีประสิทธิภาพ

WLO 4: การสอนเชิงรุกและจริยธรรมข้อมูล (Pedagogy & Defensive Coding)

ออกแบบกิจกรรมการจัดการเรียนรู้วิทยาศาสตร์บูรณาการวิทยาการคำนวณที่จัดการกับข้อผิดพลาดทั่วไป (Infinite Loops, Off-by-one, Division by Zero) และปลูกฝังจริยธรรมความซื่อสัตย์ในความถูกต้องของข้อมูลการทดลองทางวิทยาศาสตร์ (Scientific Data Integrity) โดยไม่บิดเบือนข้อมูลดิบ

การเชื่อมโยงผลลัพธ์การเรียนรู้ระดับหลักสูตร (CLO Alignment): สอดรับกับ CLO2: สามารถออกแบบและเขียนโปรแกรมคอมพิวเตอร์อย่างง่ายด้วยโปรแกรมเชิงภาพและข้อความเพื่อจำลองแบบทางวิทยาศาสตร์ และ CLO3: ตระหนักถึงความสำคัญ จริยธรรม และความรับผิดชอบในการใช้เทคโนโลยีคำนวณเพื่อการสอน

สาระสำคัญเชิงวิชาการ & สื่อทัศนศิลป์ (No Text-Wall Visual Architecture)

ในการจัดการทดลองและการวิเคราะห์ผลทางวิทยาศาสตร์ นักวิทยาศาสตร์ต้องเผชิญกับข้อมูลปริมาณมากและกระบวนการที่เกิดซ้ำ (Repetitive Processes) วิทยาการคำนวณจึงนำเสนอเครื่องมือสำคัญ 3 ประการ คือ การวนซ้ำ (Loops), ฟังก์ชัน (Functions), และ โครงสร้างข้อมูลอาร์เรย์ (Arrays/Lists) เพื่อเพิ่มความถูกต้อง แม่นยำ และประสิทธิภาพในการวิเคราะห์ผล

1. สถาปัตยกรรมการวนซ้ำในงานวิทยาศาสตร์ (Iteration Architecture: For vs. While Loops)

การวนซ้ำคือการสั่งให้ชุดคำสั่งประมวลผลซ้ำตามเงื่อนไขที่กำหนด ในการสอนและการทดลองวิทยาศาสตร์ เราแบ่งโครงสร้างลูปออกเป็น 2 ชนิดหลัก:

  • ลูปที่มีจำนวนรอบแน่นอน (Definite Iteration - for loop): ใช้เมื่อทราบจำนวนรอบการวนซ้ำที่แน่นอนล่วงหน้า เช่น การทำซ้ำการทดลอง 5 ครั้ง (5 Trials) หรือการกวาดอ่านข้อมูลอุณหภูมิตลอด 24 ชั่วโมงในอาร์เรย์
  • ลูปที่ขึ้นกับเงื่อนไขทางวิทยาศาสตร์ (Indefinite Iteration - while loop): ใช้เมื่อไม่ทราบจำนวนรอบที่แน่นอน แต่โปรแกรมจะทำงานไปเรื่อยๆ จนกว่าเงื่อนไขทางวิทยาศาสตร์จะบรรลุ เช่น การให้ความร้อนแก่สารละลายจนกระทั่งอุณหภูมิถึงจุดเดือด ($T \ge 100^\circ\text{C}$) หรือการสลายตัวของสารกัมมันตรังสีจนมวลเหลือน้อยกว่า $0.01\text{ g}$
ภาพผังที่ 6.1: สถาปัตยกรรมเปรียบเทียบการวนซ้ำทางวิทยาศาสตร์ (For Loop vs. While Loop Execution Architecture)
แสดงการเปรียบเทียบตรรกะการวนซ้ำระหว่าง For Loop (นับจำนวนรอบแน่นอน) และ While Loop (หยุดเมื่อสภาวะทางฟิสิกส์บรรลุเกณฑ์)

2. สถาปัตยกรรมฟังก์ชันและการเป็นโมดูล (Scientific Function Abstraction & Modularity)

ฟังก์ชัน (Function) ในทางวิทยาการคำนวณเปรียบเสมือน "กล่องดำทางวิทยาศาสตร์ (Scientific Blackbox)" ที่รับตัวแปรอิสระ (Input Parameters) เข้าไปประมวลผลตามกฎหรือสมการธรรมชาติ แล้วส่งคืนตัวแปรตามหรือผลลัพธ์ (Output Return Value) ออกมา ช่วยให้โค้ดเป็นไปตามหลักการ DRY (Don't Repeat Yourself) ไม่ต้องเขียนสูตรเดิมซ้ำๆ และลดข้อผิดพลาดในการคำนวณ

ภาพผังที่ 6.2: สถาปัตยกรรมฟังก์ชันวิทยาศาสตร์และการห่อหุ้มโมดูล (Scientific Function Blackbox Architecture)
แสดงโครงสร้างกล่องดำของฟังก์ชันวิทยาศาสตร์ (Input Parameters $\rightarrow$ Local Guard & Formula Execution $\rightarrow$ Return Result)

3. โครงสร้างข้อมูลลิสต์/อาร์เรย์และการประมวลผลข้อมูลอนุกรมเวลา (List/Array & Scientific Data Pipeline)

ในงานวิจัยและการทดลองวิทยาศาสตร์ ข้อมูลที่เก็บรวบรวมมักอยู่ในรูป อนุกรมเวลา (Time-series Data) หรือ ข้อมูลหลายซ้ำ (Multi-trial Data) การใช้ตัวแปรเดี่ยว ($x_1, x_2, x_3, \dots$) ทำให้การจัดการโค้ดยุ่งยากและผิดพลาดง่าย ภาษาโปรแกรมจึงใช้ List (Python) หรือ List Variable (Scratch) เพื่อเก็บชุดข้อมูลในหน่วยความจำเรียงต่อกัน

โค้ดตัวแบบจำลอง Python 3.11: โปรแกรมประมวลผลข้อมูลการทดลองและจำลองการสลายตัวกัมมันตรังสี

โปรแกรมด้านล่างนี้บูรณาการครบทั้ง ฟังก์ชัน (Functions พร้อม Type Hints และ Docstrings), การวนซ้ำ (For & While Loops), และ โครงสร้างข้อมูลลิสต์ (List Processing พร้อมการตัด Outlier) ซึ่งสามารถนำไปใช้จริงในห้องเรียนวิทยาศาสตร์: 

# ==============================================================================
# โปรแกรม: Scientific Data Processor & Radioactive Decay Simulation
# รายวิชา: 4124941 วิทยาการคำนวณสำหรับการสอนวิทยาศาสตร์ | ผศ.ดร.ชีวะ ทัศนา
# ==============================================================================
import math
from typing import List, Tuple, Dict

def analyze_lab_trials(data: List[float], outlier_threshold: float = 3.0) -> Dict[str, float]:
    """
    ฟังก์ชันคำนวณสถิติผลการทดลองวิทยาศาสตร์ N ซ้ำ พร้อมคัดกรอง Outlier
    
    Parameters:
        data: รายการข้อมูลผลการทดลองดิบ (List of measured floats)
        outlier_threshold: ค่าขีดจำกัดความคลาดเคลื่อนที่ยอมรับได้
        
    Returns:
        Dictionary สรุปค่าสถิติ (N_raw, N_clean, Mean, Min, Max)
    """
    if not data:
        raise ValueError("ชุดข้อมูลการทดลองต้องไม่เป็นค่าว่าง (Empty Dataset)")
        
    # ขั้นที่ 1: วนลูปคำนวณผลรวมดิบ (For Loop Accumulator)
    raw_sum = 0.0
    for value in data:
        raw_sum += value
    raw_mean = raw_sum / len(data)
    
    # ขั้นที่ 2: คัดกรองข้อมูลผิดปกติ (Filtering Outliers)
    clean_data: List[float] = []
    for value in data:
        if abs(value - raw_mean) <= outlier_threshold:
            clean_data.append(value)
            
    # กรณีตัด Outlier แล้วยังคงมีข้อมูล
    if not clean_data:
        clean_data = data  # Fallback
        
    # ขั้นที่ 3: คำนวณสถิติของข้อมูลที่สะอาดแล้ว
    clean_mean = sum(clean_data) / len(clean_data)
    
    return {
        "raw_count": float(len(data)),
        "clean_count": float(len(clean_data)),
        "raw_mean": round(raw_mean, 3),
        "clean_mean": round(clean_mean, 3),
        "min_value": round(min(clean_data), 3),
        "max_value": round(max(clean_data), 3)
    }

def simulate_radioactive_decay(initial_mass: float, half_life_years: float, 
                              target_remaining_ratio: float = 0.01) -> List[Tuple[int, float]]:
    """
    ฟังก์ชันจำลองการสลายตัวของสารกัมมันตรังสีด้วย While Loop
    
    Parameters:
        initial_mass: มวลเริ่มต้น (กรัม)
        half_life_years: ครึ่งชีวิตของธาตุ (ปี)
        target_remaining_ratio: สัดส่วนมวลที่เหลือเป้าหมาย (เช่น 0.01 หรือ 1%)
        
    Returns:
        List ของคู่ลำดับ (ปีที่ผ่านไป, มวลที่เหลืออยู่)
    """
    if initial_mass <= 0 or half_life_years <= 0:
        raise ValueError("มวลและครึ่งชีวิตต้องมีค่ามากกว่าศูนย์")
        
    decay_curve: List[Tuple[int, float]] = []
    current_mass = initial_mass
    current_year = 0
    dt_years = int(half_life_years)  # ก้าวเวลาเท่ากับ 1 ครึ่งชีวิต
    
    # วนซ้ำ While Loop จนกระทั่งมวลสลายตัวเหลือน้อยกว่าเกณฑ์ที่กำหนด
    while current_mass > (initial_mass * target_remaining_ratio):
        decay_curve.append((current_year, round(current_mass, 4)))
        current_mass /= 2.0  # มวลลดลงครึ่งหนึ่งในแต่ละครึ่งชีวิต
        current_year += dt_years
        
    decay_curve.append((current_year, round(current_mass, 4)))
    return decay_curve

if __name__ == "__main__":
    print("=" * 60)
    print("1. การประมวลผลข้อมูลการทดลองวัดค่า pH 6 ซ้ำ (พร้อม Outlier)")
    print("=" * 60)
    ph_raw_trials = [7.02, 6.98, 7.05, 12.50, 7.01, 6.95]  # มี 12.50 เป็น Outlier
    summary = analyze_lab_trials(ph_raw_trials, outlier_threshold=2.0)
    
    print(f"จำนวนข้อมูลดิบ: {int(summary['raw_count'])} ซ้ำ | ค่าเฉลี่ยดิบ: {summary['raw_mean']}")
    print(f"จำนวนข้อมูลที่ผ่านการกรอง: {int(summary['clean_count'])} ซ้ำ | ค่าเฉลี่ยที่แท้จริง: {summary['clean_mean']}")
    print(f"ช่วงค่าข้อมูล: {summary['min_value']} ถึง {summary['max_value']}")

    print("\n" + "=" * 60)
    print("2. การจำลองการสลายตัวของคาร์บอน-14 (C-14: ครึ่งชีวิต 5,730 ปี)")
    print("=" * 60)
    history = simulate_radioactive_decay(initial_mass=100.0, half_life_years=5730, target_remaining_ratio=0.03)
    print(f"{'รอบครึ่งชีวิต':<12}{'ปีที่ผ่านไป':<15}{'มวลที่คงเหลือ (g)':<15}")
    print("-" * 45)
    for cycle, (yr, mass) in enumerate(history):
        print(f"Cycle {cycle:<6}{yr:<15}{mass:<15}")

เกณฑ์การวัดและประเมินผลตามสภาพจริง (Authentic Assessment Rubrics)

การประเมินผลรายสัปดาห์เน้นการประเมินเพื่อพัฒนา (Formative Assessment) ตามเกณฑ์รูบริกส์จำแนก 4 ระดับคุณภาพ สอดคล้องกับมาตรฐาน WLOs ทั้ง 4 มิติ:

เกณฑ์การประเมิน ดีมาก (4 คะแนน) ดี (3 คะแนน) พอใช้ (2 คะแนน) ปรับปรุง (1 คะแนน)
1. การออกแบบตรรกะการวนซ้ำ (Loop Architecture) เลือกใช้ For/While loop ได้ถูกต้องเหมาะสมกับสถานการณ์ กำหนดเงื่อนไขสิ้นสุดชัดเจน ไม่มีโอกาสเกิด Infinite Loop 100% เลือกใช้โครงสร้าง Loop ได้ถูกต้อง เงื่อนไขถูกต้อง แต่อาจขาดการจัดการ Edge Case ในบางกรณี ใช้ Loop ได้แต่เลือกประเภทไม่ตรงกับโจทย์ หรือมีโครงสร้างที่อาจเสี่ยงต่อการวนซ้ำไม่สิ้นสุด เขียนลูปผิดพลาด เกิด Infinite Loop หรือไม่เข้าใจความแตกต่างระหว่าง For และ While
2. สถาปัตยกรรมฟังก์ชัน (Functional Abstraction) สร้างฟังก์ชันที่มีพารามิเตอร์และส่งค่ากลับถูกต้อง มี Defensive Guard ดักจับ Error มี Docstring และ Type Hints สมบูรณ์ สร้างฟังก์ชันและส่งค่ากลับได้ถูกต้อง ตัวแปรแยกเป็นอิสระ (Local Scope) แต่ยังขาด Defensive Guard สร้างฟังก์ชันได้ แต่ใช้ตัวแปรส่วนกลาง (Global Scope) ปะปน หรือลืมส่งค่ากลับ (Missing Return) ไม่สามารถสร้างฟังก์ชันแยกเป็นโมดูลได้ ยังคงเขียนโค้ดแบบคำสั่งเดียวเรียงยาวทั้งหมด
3. การประมวลผลข้อมูลอาร์เรย์ (Array Data Processing) จัดการข้อมูลใน List ได้อย่างสมบูรณ์ คำนวณสถิติถูกต้อง มีระบบป้องกัน IndexError และตัด Outlier ได้อย่างเป็นเหตุเป็นผล เก็บข้อมูลใน List และใช้ลูปหาผลรวม/ค่าเฉลี่ยได้ถูกต้อง ดัชนีไม่คลาดเคลื่อน ใช้ List เก็บข้อมูลได้ แต่การเข้าถึงดัชนีคลาดเคลื่อน (Off-by-one Error) หรือคำนวณผลรวมผิด ไม่สามารถใช้ List ในการเก็บและประมวลผลข้อมูลการทดลองได้
4. การบูรณาการวิทย์และจริยธรรมข้อมูล (Pedagogy & Data Ethics) แบบจำลองสะท้อนกฎธรรมชาติอย่างสมบูรณ์ รักษาความถูกต้องของข้อมูลดิบ และสามารถออกแบบกิจกรรมสอนนักเรียนได้อย่างสร้างสรรค์ แบบจำลองทางวิทยาศาสตร์ถูกต้อง ข้อมูลไม่บิดเบือน มีแนวทางการจัดการเรียนรู้ที่ชัดเจน แบบจำลองมีจุดคลาดเคลื่อนทางวิทยาศาสตร์บางส่วน ขาดการอธิบายความเชื่อมโยงกับแนวคิดรวบยอด แบบจำลองขัดกับกฎทางวิทยาศาสตร์ หรือมีการแก้ไขตกแต่งผลการทดลองโดยไม่สุจริต

แบบทดสอบวัดทักษะการคิดขั้นสูง (Higher-Order Thinking Skills: HOTS) ด้านการวิเคราะห์ข้อผิดพลาด (Analyzing) และการประเมินเงื่อนไขการวนซ้ำ (Evaluating) ตามแนวทางของ สสวท.:

ข้อที่ 1 (ระดับการวิเคราะห์ - Analyzing):
ครูวิทยาศาสตร์ท่านหนึ่งให้นักเรียนเขียนโปรแกรมภาษา Python เพื่อหาค่าเฉลี่ยของอุณหภูมิที่วัดได้จากการทดลอง 5 ซ้ำ โดยนักเรียนเขียนโค้ดดังนี้: 
temps = [24.5, 25.2, 24.8, 25.0, 24.9]
total = 0.0
for i in range(1, len(temps) + 1):
    total = total + temps[i]
mean_temp = total / len(temps)
print("อุณหภูมิเฉลี่ย =", mean_temp)
เมื่อนักเรียนสั่งรันโปรแกรมนี้ โปรแกรมเกิดข้อผิดพลาดและยุติการทำงานกะทันหัน ข้อใดวิเคราะห์สาเหตุและแนวทางแก้ไขได้อย่างถูกต้องที่สุด?
  • ก. เกิดข้อผิดพลาด ZeroDivisionError เนื่องจาก len(temps) มีค่าเป็น 0 ต้องแก้ไขโดยการกำหนดค่าเริ่มต้น total = 1.0
  • ข. เกิดข้อผิดพลาด TypeError เพราะตัวแปร total ไม่สามารถนำไปบวกกับข้อมูลทศนิยมในลิสต์ได้ ต้องแปลงเป็น float(total)
  • ค. เกิดข้อผิดพลาด IndexError: list index out of range เนื่องจากดัชนีของลิสต์ใน Python เริ่มต้นจาก 0 ถึง 4 แต่ลูปเข้าถึงดัชนี 1 ถึง 5 ต้องแก้เป็น for i in range(len(temps)): หรือ for t in temps:
  • ง. เกิดข้อผิดพลาด SyntaxError เพราะคำสั่ง range ไม่สามารถรับค่าที่บวกหนึ่งได้ ต้องแก้เป็น range(len(temps))
เฉลยข้อ ค. ถูกต้อง!
การวิเคราะห์เชิงลึก: ในภาษา Python (และภาษาคอมพิวเตอร์ส่วนใหญ่) โครงสร้างข้อมูลลิสต์ใช้การอ้างอิงตำแหน่งแบบ Zero-based Indexing ซึ่งลิสต์ temps ที่มีสมาชิก 5 ตัว จะมีตำแหน่งดัชนีคือ 0, 1, 2, 3, 4 เท่านั้น
คำสั่ง range(1, len(temps) + 1) คือ range(1, 6) ซึ่งจะสร้างลำดับตัวเลข 1, 2, 3, 4, 5 ส่งผลให้:
  • ค่า temps[0] (24.5) ข้อมูลตัวแรก ถูกละเว้นไม่ได้นำมารวม (Off-by-one Error)
  • เมื่อลูปทำงานถึงรอบสุดท้าย i = 5 โปรแกรมพยายามเข้าถึง temps[5] ซึ่งไม่มีตำแหน่งนี้ในหน่วยความจำ จึงเกิดข้อผิดพลาด IndexError: list index out of range ทันที
แนวทางแก้ไขที่ดีที่สุดตามหลัก Pythonic: ควรเขียน for t in temps: total += t ซึ่งปลอดภัยและไม่ต้องอ้างอิงตัวเลขดัชนี
ข้อที่ 2 (ระดับการประเมินค่า - Evaluating):
นักศึกษาต้องการจำลองการสลายตัวของสารกัมมันตรังสีไอโอดีน-131 (I-131 ซึ่งมีครึ่งชีวิต 8 วัน) จากมวลเริ่มต้น 80 กรัม โดยต้องการคำนวณว่าต้องใช้เวลากี่วัน สารจึงจะสลายตัวจนเหลือน้อยกว่าหรือเท่ากับ 5 กรัม จึงเขียนฟังก์ชัน Python ดังนี้: 
def calculate_decay_days(initial_mass, target_mass, half_life):
    days = 0
    mass = initial_mass
    while mass > target_mass:
        mass = mass / 2
        days = days + half_life
    return days, mass

total_days, final_mass = calculate_decay_days(80, 5, 8)
พิจารณาผลลัพธ์ของ total_days และ final_mass หลังฟังก์ชันทำงานเสร็จสิ้น คือข้อใด?
  • ก. total_days = 24 วัน, final_mass = 10.0 กรัม
  • ข. total_days = 32 วัน, final_mass = 5.0 กรัม
  • ค. total_days = 40 วัน, final_mass = 2.5 กรัม
  • ง. เกิด Infinite Loop เพราะ mass ไม่มีวันลดลงต่ำกว่า 0 ได้
เฉลยข้อ ข. ถูกต้อง!
