WLO 1: ด้านพุทธิพิสัย

อธิบายทฤษฎีและกลไกของ Pattern Recognition และ Algorithm Design ในฐานะเครื่องมือทางญาณวิทยาในการสังเคราะห์กฎและหลักการทางวิทยาศาสตร์จากข้อมูลเชิงประจักษ์ (Empirical Evidence)

WLO 2: ด้านทักษะการวิเคราะห์

WLO 3: ด้านทักษะกระบวนการ

สร้างสรรค์และเขียนขั้นตอนวิธีที่มีคุณสมบัติ Definiteness, Finiteness, Correctness พร้อมวิเคราะห์ประสิทธิภาพความซับซ้อนเชิงเวลา (\(\mathcal{O}(N)\) vs \(\mathcal{O}(\log N)\)) ในการจัดเรียงและการสืบค้นข้อมูล

WLO 4: ด้านการจัดการเรียนรู้

ตารางที่ 3.1: มิติการสกัดรูปแบบ (Pattern Recognition) ข้ามสาขาวิชาวิทยาศาสตร์

สาขาวิทยาศาสตร์ ปรากฏการณ์ / ข้อมูลเชิงประจักษ์ รูปแบบที่ตรวจพบ (Identified Pattern) การแปลงเป็นขั้นตอนวิธี / แบบจำลองพยากรณ์
ฟิสิกส์ (Physics) การสั่นของมวลติดสปริง และการแกว่งของลูกตุ้มอย่างง่าย การเคลื่อนที่เป็นคาบซ้ำสม่ำเสมอ กราฟการกระจัด-เวลาเป็นรูปไซน์ (\(\sin / \cos\)) พลังงานกลรวมอนุรักษ์ ขั้นตอนวิธีคำนวณตำแหน่งวัตถุ ณ เวลา \(t\) ใดๆ ด้วยสมการ \(x(t) = A\cos(\omega t + \phi)\)
เคมี (Chemistry) คุณสมบัติทางกายภาพและเคมีของธาตุ 118 ชนิด แนวโน้มค่าอิเล็กโทรเนกาติวิตี (\(EN\)), รัศมีอะตอม, และพลังงาน \(IE\) เปลี่ยนแปลงเป็นรอบตามคาบและหมู่ ขั้นตอนวิธีการจัดหมวดหมู่ธาตุ (Periodic Classification) และอัลกอริทึมทำนายความว่องไวในการทำปฏิกิริยา
ชีววิทยา (Biology) ลักษณะรุ่นลูกจากการผสมพันธุ์ถั่วลันเตาของเมนเดล สัดส่วนฟีโนไทป์รุ่นที่ 2 ปรากฏอัตราส่วนคงที่ \(3:1\) (Monohybrid) และ \(9:3:3:1\) (Dihybrid) อัลกอริทึมการคำนวณความน่าจะเป็นของพันธุศาสตร์เมนเดล (Punnett Square Algorithm)
โลกและดาราศาสตร์ ระดับน้ำขึ้น-น้ำลง และตำแหน่งของดวงจันทร์รอบโลก น้ำเกิด-น้ำตาย เกิดขึ้นตามรอบข้างขึ้น-ข้างแรม สัมพันธ์กับตำแหน่งดวงอาทิตย์ โลก และดวงจันทร์ ขั้นตอนวิธีการพยากรณ์เวลาน้ำขึ้นสูงสุด-ต่ำสุดเพื่อการเดินเรือและการเกษตรชายฝั่ง

อัลกอริทึมการสืบค้นข้อมูลวิทยาศาสตร์ (Searching: Linear vs Binary Search)

ในการวิจัยและการทดลองทางวิทยาศาสตร์ นักวิจัยต้องสืบค้นข้อมูลในฐานข้อมูลขนาดใหญ่ เช่น ตารางธาตุ 118 ธาตุ หรือฐานข้อมูลสารเคมีนับพันชนิด หากใช้วิธีค้นหาแบบเรียงลำดับทีละตัว (Linear Search) จะเสียเวลาอย่างมาก หากข้อมูลได้รับการจัดเรียงไว้แล้ว เราสามารถใช้วิธีการ ค้นหาแบบทวิภาค (Binary Search) ซึ่งใช้หลักการแบ่งแยกและเอาชนะ (Divide and Conquer) ลดจำนวนรอบการสืบค้นลงอย่างมหาศาลจาก \(\mathcal{O}(N)\) เหลือเพียง \(\mathcal{O}(\log_2 N)\) (สสวท. กิจกรรมที่ 7; Stoika & Temetev, 2026):

# =====================================================================
# โครงการ: แบบจำลองการตรวจจับรูปแบบทางวิทยาศาสตร์และอัลกอริทึมสืบค้น
# ผู้พัฒนา: ผู้ช่วยศาสตราจารย์ ดร.ชีวะ ทัศนา
# สังกัด: คณะวิทยาศาสตร์และเทคโนโลยี มหาวิทยาลัยราชภัฏรำไพพรรณี
# =====================================================================

from typing import List, Tuple, Dict, Optional

# ---------------------------------------------------------------------
# 1. PATTERN RECOGNITION: ตรวจจับจุดเปลี่ยนเว้า (Equivalence Point Inflection)
# ในการไทเทรตกรด-เบส รูปแบบสำคัญคือ "อัตราการเปลี่ยนแปลง pH ต่อนิวเคลียสปริมาตร" (dpH/dV)
# ---------------------------------------------------------------------
def detect_titration_equivalence_point(data_points: List[Tuple[float, float]]) -> Tuple[float, float, float]:
    """
    ตรวจจับรูปแบบจุดสมมูลของการไทเทรต โดยการหาอนุพันธ์อันดับ 1 สูงสุด (Max dpH/dV)
    data_points: รายการคู่ลำดับ (ปริมาตรไทแทรนต์ mL, ค่า pH ที่วัดได้)
    คืนค่า: (ปริมาตร ณ จุดสมมูล, ค่า pH ณ จุดสมมูล, อัตราความชันสูงสุด)
    """
    max_slope = -1.0
    eq_volume = 0.0
    eq_ph = 0.0
    
    for i in range(len(data_points) - 1):
        v1, ph1 = data_points[i]
        v2, ph2 = data_points[i+1]
        
        delta_v = v2 - v1
        if delta_v > 0:
            slope = abs(ph2 - ph1) / delta_v  # dpH / dV (Pattern of inflection)
            if slope > max_slope:
                max_slope = slope
                eq_volume = (v1 + v2) / 2.0
                eq_ph = (ph1 + ph2) / 2.0
                
    return eq_volume, eq_ph, max_slope


# ---------------------------------------------------------------------
# 2. SORTING ALGORITHM: Bubble Sort จัดเรียงข้อมูลตัวอย่างสารเคมีตามความหนาแน่น
# ---------------------------------------------------------------------
def bubble_sort_reagents_by_density(reagents: List[Dict]) -> Tuple[List[Dict], int]:
    """
    จัดเรียงสารเคมีตามความหนาแน่น (Density g/cm3) จากน้อยไปมาก
    คืนค่า: (รายการที่จัดเรียงแล้ว, จำนวนรอบการสลับข้อมูล Swap Count)
    """
    n = len(reagents)
    sorted_list = reagents.copy()
    swap_count = 0
    
    for i in range(n - 1):
        swapped = False
        for j in range(0, n - i - 1):
            if sorted_list[j]["density"] > sorted_list[j + 1]["density"]:
                sorted_list[j], sorted_list[j + 1] = sorted_list[j + 1], sorted_list[j]
                swap_count += 1
                swapped = True
        if not swapped:
            break  # Best-case optimization O(N)
            
    return sorted_list, swap_count


# ---------------------------------------------------------------------
# 3. SEARCHING ALGORITHM: Binary Search สืบค้นธาตุตามเลขอะตอม O(log N)
# ---------------------------------------------------------------------
def binary_search_element(elements: List[Dict], target_atomic_num: int) -> Tuple[Optional[Dict], int]:
    """
    สืบค้นธาตุเคมีที่มีเลขอะตอม target_atomic_num ในรายการที่เรียงลำดับแล้ว
    คืนค่า: (ข้อมูลธาตุที่พบ หรือ None, จำนวนรอบที่ใช้ในการเปรียบเทียบ)
    """
    low = 0
    high = len(elements) - 1
    steps = 0
    
    while low <= high:
        steps += 1
        mid = (low + high) // 2
        mid_val = elements[mid]["atomic_number"]
        
        if mid_val == target_atomic_num:
            return elements[mid], steps
        elif mid_val < target_atomic_num:
            low = mid + 1
        else
            high = mid - 1
            
    return None, steps

if __name__ == "__main__":
    print("=== [1] ทดสอบการตรวจจับรูปแบบ (Pattern Recognition: Titration Point) ===")
    titration_data = [
        (0.0, 2.85), (5.0, 3.15), (10.0, 3.55), (15.0, 4.05),

        (21.0, 11.20), (25.0, 11.85)
    ]

    print(f"พบรูปแบบจุดเปลี่ยนเว้า (Equivalence Point) ที่: ปริมาตร {eq_v:.2f} mL, pH = {eq_ph:.2f}")
    print(f"ความชันสูงสุด (Maximum dpH/dV) = {slope:.2f} pH/mL\n")

    print("=== [2] ทดสอบ Bubble Sort เรียงลำดับสารเคมีตามความหนาแน่น ===")
    reagents = [
        {"name": "Glycerin", "density": 1.26},
        {"name": "Ethanol", "density": 0.789},
        {"name": "Water", "density": 1.00},
        {"name": "Chloroform", "density": 1.49}

    for r in sorted_reagents:
        print(f"- {r['name']:<12} ความหนาแน่น: {r['density']:.3f} g/cm³")
    print(f"จำนวนครั้งที่มีการสลับที่ (Swaps): {swaps} ครั้ง\n")

    print("=== [3] ทดสอบ Binary Search ค้นหาธาตุในตารางธาตุ O(log N) ===")
    periodic_sample = [
        {"atomic_number": 1, "name": "Hydrogen", "symbol": "H"},

    แต่ละกลุ่มเลือกหัวข้อการทดลองวิทยาศาสตร์ 1 การทดลอง (เช่น 1. การสกัดดีเอ็นเอจากกล้วยหอม, 2. การไทเทรตกรดไฮโดรคลอริกกับโซเดียมไฮดรอกไซด์, 3. การทดสอบกฎของโอห์มในวงจรไฟฟ้า) จากนั้นแปลงคู่มือการทดลองให้กลายเป็น "ขั้นตอนวิธีเชิงประมวลผล" โดยต้องมีองค์ประกอบครบ 5 ส่วน:

    • Pre-condition (ข้อมูลนำเข้า/อุปกรณ์เริ่มต้น): สารละลาย ปริมาตร ความเข้มข้น
    • Sequence (ลำดับขั้นตอนที่แน่นอน): ห้ามใช้คำกำกวม เช่น "คนสารให้พอเหมาะ" แต่ต้องระบุ "คนด้วยแท่งแก้ว 30 วินาทีตามเข็มนาฬิกา"
    • Decision Points (เงื่อนไข If-Else): "ถ้าสารละลายเปลี่ยนเป็นสีชมพูจาง ให้หยุดหยดทันที มิฉะนั้นให้หยดต่อครั้งละ 0.2 mL"
    • Iteration/Loop (การวนซ้ำ): การทำซ้ำ 3 ซ้ำเพื่อหาค่าเฉลี่ย
    • Post-condition (ผลลัพธ์/ข้อมูลส่งออก): ตารางผลการทดลองที่ปราศจากความคลาดเคลื่อนเชิงระบบ

เกณฑ์การวัดและประเมินผลการเรียนรู้ (Authentic Rubrics Matrix)

เกณฑ์การประเมินชิ้นงานการออกแบบขั้นตอนวิธีและการสกัดรูปแบบทางวิทยาศาสตร์ 4 ระดับคุณภาพ พัฒนาตามเกณฑ์มาตรฐานการประเมินทักษะการคิดเชิงคำนวณในครูวิทยาศาสตร์ (Listiaji, Amelia, & Molnár, 2026; Saxena et al., 2019):

มิติการประเมิน ดีมาก (4 คะแนน) ดี (3 คะแนน) พอใช้ (2 คะแนน) ปรับปรุง (1 คะแนน)
1. การตรวจจับและสกัดรูปแบบ (Pattern Extraction) ระบุความสัมพันธ์ แนวโน้มเชิงฟังก์ชัน และคุณลักษณะคงตัว (Invariants) จากข้อมูลวิทยาศาสตร์ได้อย่างถูกต้องสมบูรณ์ พร้อมให้เหตุผลทางทฤษฎีรองรับอย่างชัดเจน ระบุแนวโน้มและรูปแบบหลักได้ถูกต้องเป็นส่วนใหญ่ แต่ยังขาดการอธิบายคุณลักษณะคงตัวในบางจุด ระบุได้เพียงรูปแบบพื้นฐานผิวเผิน (เช่น ตัวเลขเพิ่มขึ้น/ลดลง) แต่ไม่สามารถเชื่อมโยงเป็นกฎหรือฟังก์ชันได้ ระบุรูปแบบคลาดเคลื่อน หรือไม่สามารถแยกแยะความแตกต่างระหว่างความบังเอิญกับรูปแบบทางวิทยาศาสตร์ได้
2. ความชัดเจนและรัดกุมของขั้นตอนวิธี (Algorithmic Precision) ขั้นตอนวิธีมีความละเอียด ปราศจากความกำกวม (Definite) มีจุดเริ่มต้น-จุดสิ้นสุดชัดเจน (Finite) มีโครงสร้างเงื่อนไขและลูปที่ถูกต้องสมบูรณ์ 100% ขั้นตอนวิธีมีความชัดเจน มีโครงสร้างลำดับที่ดี มีจุดกำกวมเล็กน้อยที่ไม่ส่งผลต่อผลลัพธ์สุดท้าย ขั้นตอนวิธีมีข้อผิดพลาดบางจุด เช่น ขาดเงื่อนไขการหยุดลูป หรือมีขั้นตอนที่ข้ามกระบวนการสำคัญไป ขั้นตอนวิธีกำกวมมาก ไม่เป็นลำดับ ไม่สามารถนำไปให้หุ่นยนต์หรือผู้อื่นปฏิบัติตามได้จริง
3. การวิเคราะห์ประสิทธิภาพ (Complexity Reasoning) วิเคราะห์ความซับซ้อนเชิงเวลา (\(\mathcal{O}(N)\) vs \(\mathcal{O}(\log N)\)) ได้อย่างถูกต้อง สามารถเปรียบเทียบข้อดี-ข้อจำกัดระหว่าง Bubble Sort, Selection Sort และ Binary Search ได้อย่างลึกซึ้ง เข้าใจความแตกต่างของประสิทธิภาพอัลกอริทึม สามารถบอกได้ว่าวิธีใดเร็วกว่าในกรณีข้อมูลขนาดใหญ่ บอกชื่อความซับซ้อนได้ แต่ยังสับสนในการอธิบายเหตุผลว่าทำไม Binary Search จึงเร็วกว่า Linear Search ไม่สามารถอธิบายประสิทธิภาพหรือความซับซ้อนของขั้นตอนวิธีได้
4. การประยุกต์สู่การจัดการเรียนรู้ (Pedagogical Integration) ออกแบบกิจกรรม Unplugged/Plugged สอดคล้องกับเนื้อหาวิทยาศาสตร์ระดับมัธยม มีการเสริมสร้างกระบวนการคิดของนักเรียนได้อย่างโดดเด่นและสร้างสรรค์ ออกแบบกิจกรรมการเรียนรู้ได้น่าสนใจ สอดคล้องกับสาระวิทยาการคำนวณและวิทยาศาสตร์ได้ดี กิจกรรมการเรียนรู้เน้นเฉพาะการสอนโค้ดหรือการทดลองอย่างใดอย่างหนึ่ง ขาดการผสานที่กลมกลืน กิจกรรมไม่สอดคล้องกับระดับพัฒนาการของผู้เรียน และไม่สะท้อนแนวคิดเชิงคำนวณ

สสวท. หมวด CT-Pattern

สถานการณ์: นักชีววิทยาสำรวจสิ่งมีชีวิตในทะเลลึก 12 ชนิดที่ไม่เคยค้นพบมาก่อน จากการเก็บข้อมูลกายภาพพบว่า:

  • สัตว์ 11 ใน 12 ชนิดมีอวัยวะเรืองแสงได้ (Bioluminescence) โดยอาศัยแบคทีเรียชีวภาพ
  • สัตว์ทั้ง 12 ชนิดไม่มีเม็ดสีที่ผิวหนัง (ลำตัวโปร่งใสหรือสีขาวซีด)
  • สัตว์ 10 ชนิดมีดวงตาขนาดใหญ่พิเศษที่ไวต่อแสง หรือไม่มีดวงตาเลยอย่างสิ้นเชิง

จากสถานการณ์ข้างต้น การที่นักวิทยาศาสตร์สรุปว่า "สิ่งมีชีวิตในเขตน้ำลึกพัฒนาอวัยวะเรืองแสงและสูญเสียเม็ดสีผิวเพื่อปรับตัวต่อสภาวะมืดมิดถาวร" ถือเป็นการใช้เสาหลักใดของแนวคิดเชิงคำนวณเป็นแกนนำ?

ก. การแยกส่วนประกอบ (Decomposition) เพราะแยกกายวิภาคของสัตว์ออกเป็นระบบย่อย
ข. การหารูปแบบ (Pattern Recognition) เพราะตรวจจับคุณลักษณะร่วมที่เกิดขึ้นซ้ำๆ (Invariant Traits) ท่ามกลางสัตว์ต่างสปีชีส์เพื่อสร้างข้อสรุปทั่วไป
ค. การคิดเชิงนามธรรม (Abstraction) เพราะตัดข้อมูลเรื่องอุณหภูมิน้ำทะเลออกไป
ง. การออกแบบขั้นตอนวิธี (Algorithm Design) เพราะเขียนลำดับการผ่าตัดสัตว์ทดลอง
เฉลย: ข. การหารูปแบบ (Pattern Recognition)
บทวิเคราะห์เชิงวิทยาการคำนวณ: นักวิทยาศาสตร์มองหาความคล้ายคลึง (Similarities) และลักษณะร่วมที่คงตัว (Invariants) ในกลุ่มตัวอย่างอิสระ แล้วนำรูปแบบความสัมพันธ์ระหว่างลักษณะทางกายวิภาคกับปัจจัยสิ่งแวดล้อมมาสังเคราะห์เป็นกฎวิวัฒนาการ ซึ่งตรงกับนิยามของ Pattern Extraction ตามกรอบ Weintrop et al. (2016)

ข้อที่ 2: ประสิทธิภาพการสืบค้นข้อมูลในฐานข้อมูลสารเคมีขนาดใหญ่ (HOTS: Evaluating)

สสวท. หมวด Algorithm-Efficiency

สถานการณ์: ห้องปฏิบัติการชีวเคมีมีฐานข้อมูลสารประกอบอินทรีย์จำนวน \(N = 1,024\) รายการ ซึ่งได้รับการจัดเรียงตามลำดับจุดเดือด (\(^\circ\text{C}\)) จากน้อยไปมากเรียบร้อยแล้ว นักวิจัยต้องการค้นหาสารที่มีจุดเดือดเท่ากับ \(178.5^\circ\text{C}\) พอดี

หากนักวิจัยเปลี่ยนจากการค้นหาแบบเรียงลำดับ (Linear Search) ไปใช้การค้นหาแบบทวิภาค (Binary Search) จำนวนครั้งในการเปรียบเทียบในกรณีที่แย่ที่สุด (Worst-case) จะลดลงมากที่สุดกี่ครั้ง?

ก. ลดลง 512 ครั้ง
ข. ลดลง 1,014 ครั้ง (จาก 1,024 ครั้ง เหลือเพียง 10 ครั้ง)
ค. ลดลง 1,023 ครั้ง (จาก 1,024 ครั้ง เหลือเพียง 1 ครั้ง)
ง. ไม่ลดลงเลย เพราะข้อมูลจุดเดือดเป็นเลขทศนิยมไม่สามารถค้นหาแบบทวิภาคได้
เฉลย: ข. ลดลง 1,014 ครั้ง (จาก 1,024 ครั้ง เหลือเพียง 10 ครั้ง)
บทวิเคราะห์เชิงคณิตศาสตร์และวิทยาการคำนวณ:
1. สำหรับ Linear Search ในกรณีแย่ที่สุด (Worst-case เมื่อสารอยู่ท้ายสุดหรือไม่มีในฐานข้อมูล) ต้องตรวจสอบครบทุกช่อง = \(N = 1,024\) ครั้ง
2. สำหรับ Binary Search ข้อมูลที่เรียงลำดับแล้วจะถูกแบ่งครึ่งช่วงทีละ 2 เสมอ จำนวนครั้งสูงสุดคือ \(\lceil \log_2(1,024) \rceil = 10\) ครั้ง เนื่องจาก \(2^{10} = 1,024\)
3. ผลต่างของจำนวนครั้งที่ลดลง = \(1,024 - 10 = 1,014\) ครั้ง สะท้อนให้เห็นประสิทธิภาพอันมหาศาลของขั้นตอนวิธีที่ดีในการจัดการข้อมูลวิทยาศาสตร์
