# ตัวสะสมผลรวมข้อมูล:
total = 0
for i in range(0, 10, 1):
total += data[i]
ปรับพารามิเตอร์ Range()
จุดเริ่มต้น (Start): 0
จุดสิ้นสุด (Stop): 10
ขนาดก้าว (Step): 1
การประยุกต์ในการสอนวิทยาศาสตร์
การประมวลผลข้อมูลอนุกรมเวลา (Time Series):
ข้อมูลฟิสิกส์ เช่น การบันทึกตำแหน่งของลูกตุ้มทุกๆ 0.01 วินาที หรืออุณหภูมิเซนเซอร์ ถูกเก็บเป็น Array คอมพิวเตอร์ต้องใช้ for-loop ในการคำนวณอัตราเร็วเฉลี่ย
Range(start, stop, step):
ข้อควรระวัง: ในภาษา Python ค่า stop จะ ไม่ถูกนับรวม เช่น range(0, 10) จะวนลูปถึงแค่เลข 9 เท่านั้น!
