คู่มือวิทยากร: กิจกรรมหุ่นยนต์มนุษย์ (1.30 ชม.)

เป้าหมาย: สอนตรรกะพื้นฐาน ลำดับขั้นตอน และการแก้ปัญหา (Debugging)

🕒 การบริหารเวลา (Time Management)

15 นาที

ช่วงที่ 1: Introduction & Robot Logic

อธิบายว่าคอมพิวเตอร์คืออะไร และ "ทำไมมันถึงโง่" (ทำงานตามสั่งเท่านั้น) สาธิตการเป็นหุ่นยนต์ที่เดินชนกำแพงหากไม่มีคำสั่งหยุด

15 นาที

ช่วงที่ 2: Training (ด่านฝึกหัด)

แบ่งกลุ่ม 4 คน ให้ลองใช้บัตรเบื้องต้น (เดินหน้า/เลี้ยว) เพื่อทำความเข้าใจบทบาท Robot และ Programmer

45 นาที

ช่วงที่ 3: The Palace Quest (ภารกิจหลัก)

ใช้บัตรคำสั่งทั้งหมด (รวม Loop และเงื่อนไข) เพื่อผ่านด่านที่วิทยากรตั้งไว้ให้ซับซ้อนขึ้น

15 นาที

ช่วงที่ 4: Summary & Reflection

ถอดบทเรียนเรื่อง "Bug" และ "Algorithm" และทำไมลำดับความคิดถึงสำคัญกว่าการลงมือพิมพ์โค้ด

🎮 ขั้นตอนการจัดกิจกรรมภาคสนาม (5 Steps Guide)

1. การเตรียมพื้นที่ (Setup)

ใช้เทปกาวสี (Masking Tape) ตีเส้นตารางขนาด 5x5 บนพื้นห้อง (ช่องละ 50x50 ซม.) วางก้อนหินและขุมทรัพย์ตามแผนที่

2. แบ่งบทบาท (Roles)

Programmer (วางแผน), Robot (เดินตามสั่ง), Checker (ตรวจสอบความถูกต้อง)

3. ช่วงวางแผน (Coding)

Programmer เรียงบัตรคำสั่งบนโต๊ะข้างสนามตามลำดับที่ต้องการ (ห้าม Robot ดูจนกว่าจะเสร็จ)

4. ช่วงรันโปรแกรม (Execution)

Programmer ชี้บัตรทีละใบและอ่านออกเสียง Robot เดินตามเป๊ะๆ ห้าม Programmer พูดแนะนำเพิ่ม

⚠️ กติกาศักดิ์สิทธิ์:
  • Robot ห้ามคิดเอง: ต้องรอฟังคำสั่งจาก Programmer เท่านั้น
  • The BUG Call: หาก Robot เดินผิดขั้นตอน ให้ตะโกนว่า "BUG!" และต้องกลับไปจุด Start ใหม่
  • Silent Run: เมื่อเริ่มเดินแล้ว Programmer ห้ามพูดแก้ไข ต้องให้โปรแกรมรันจนจบ

🏠 การจัดห้องเรียน (Room Setup)

The 5x5 Grid: ใช้เทปกาวสี (Masking Tape) แปะที่พื้นเป็นตาราง 5x5 ช่อง

Goal
Rock

วาง "อุปสรรค" (หมอน, กล่อง) ไว้ตามจุดต่างๆ เพื่อให้นักเรียนต้องวางแผนอ้อม

🎬 เครื่องมือช่วยสอน: โปรแกรมจำลอง (Interactive Sim)

ก่อนเริ่มเล่นจริง วิทยากรสามารถใช้โปรแกรมจำลองเพื่อสาธิตวิธีการวางบัตรคำสั่งให้นักเรียนดูผ่านหน้าจอได้

🚀 เปิดโปรแกรมจำลอง (Logic Sim) 🗺️ ดูแผนผังการจัดสนาม (Mission Maps)

🏆 เกณฑ์การให้คะแนน (Scoring Rubric)

หัวข้อการประเมิน ระดับคะแนน (1-5 ⭐) เกณฑ์การตัดสิน
Algorithm Accuracy ⭐⭐⭐⭐⭐ Robot เดินถึงจุดหมายได้ถูกต้องในรอบเดียว (No Bugs)
Debugging Skill ⭐⭐⭐⭐ หากมีข้อผิดพลาด สามารถแก้ไข (Debug) และทำสำเร็จในรอบที่ 2
Code Efficiency ⭐⭐⭐⭐⭐ มีการใช้บัตร Loop เพื่อลดจำนวนบัตรคำสั่งที่ซ้ำซ้อน
Role Performance ⭐⭐⭐⭐ Robot ทำตามคำสั่งได้เป๊ะ และ Programmer สื่อสารด้วยบัตรเท่านั้น
รางวัลพิเศษ (Master Programmer Award): มอบให้กลุ่มที่ใช้จำนวนบัตรน้อยที่สุด (Shortest Code) ในการผ่านด่านที่ยากที่สุด
