GAME 01: Star Catcher (ป.1-ป.3)

1

สร้างตัวละครและควบคุม

Set [mySprite] to sprite [🐱] of kind [Player]

Move [mySprite] with buttons
2

สร้างดวงดาวแบบสุ่ม

On Start: Set [star] to sprite [⭐] of kind [Food]

Set [star] position to x [random 0-160] y [random 0-120]
3

ตรรกะการเก็บไอเทม

On [Player] overlaps [Food]:

Change score by [1]

Set [Food] position to x [random] y [random]

GAME 02: Hungry Dino (ป.3-ป.4)

!

หัวใจสำคัญ: ใช้คำสั่ง On Game Update every 2000 ms เพื่อสุ่มสร้าง "ลูกไฟ" (Enemy) ให้พุ่งออกมาจากขอบจอ และใช้ Change Life by -1 เมื่อชนกัน

GAME 03: Classic Platformer (ป.4-ป.6)

!

หัวใจสำคัญ: ต้องตั้งค่า Set [mySprite] ay (acceleration y) to 300 เพื่อสร้างแรงโน้มถ่วง และใช้ Scene -> Set Tilemap เพื่อวาดด่านที่ตัวละครเดินเหยียบได้
