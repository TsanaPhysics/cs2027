🗺️ ดูแผนผังภารกิจ

เปิดประตูสู่โลกโค้ด: กิจกรรมหุ่นยนต์มนุษย์

เรียนรู้ตรรกะคอมพิวเตอร์ผ่านการเล่นแบบ Unplugged (ไม่ต้องใช้คอมพิวเตอร์)

🎯 เป้าหมายของกิจกรรม

เพื่อให้นักเรียนเข้าใจว่า "คอมพิวเตอร์ทำงานตามคำสั่งที่ชัดเจนเท่านั้น" และการเขียนโค้ดคือการวางลำดับขั้นตอน (Algorithm) ให้ถูกต้อง

  • ✅ Programmer: ผู้วางแผนและให้ชุดคำสั่ง
  • 🤖 Robot: ผู้ทำตามคำสั่งอย่างเคร่งครัด (ห้ามคิดเอง!)
  • 🚩 The Grid: ตารางบนพื้นที่เป็นเส้นทางการเดิน

🎴 บัตรคำสั่ง (Command Cards)

⬆️ เดินหน้า (Forward)

ก้าวไปข้างหน้า 1 ช่องตาราง

⬅️ หมุนซ้าย (Turn Left)

หมุนตัวไปทางซ้าย 90 องศา

➡️ หมุนขวา (Turn Right)

หมุนตัวไปทางขวา 90 องศา

✋ หยิบของ (Pick Up)

หยิบสมบัติในช่องที่ยืนอยู่

🚀 เปิดโปรแกรมจำลอง (Logic Sim) 🗺️ ดูแผนผังการจัดสนาม (Mission Maps)

🧠 ตรรกะขั้นสูง (Advanced Logic)

เพื่อให้การเขียนโค้ดมีประสิทธิภาพ เราจะใช้บัตรคำสั่งพิเศษเพิ่มเติม:

  • 🔄 Loop: สั่งให้ทำซ้ำ (เช่น เดินหน้า 5 ครั้ง)
  • ⚖️ If-Else: การตัดสินใจ (เช่น ถ้าเจออุปสรรค ให้เลี้ยวขวา)
  • ⭐ Variables: การเก็บข้อมูล (เช่น คะแนนหรือจำนวนสมบัติ)

🗺️ ตัวอย่างแผนที่ภารกิจ (Mission Map)

นักเรียนต้องวางแผนเส้นทางเพื่อเลี่ยงก้อนหินและไปให้ถึงหีบสมบัติ!

🛠️ ขั้นตอนการเล่น

🏰 ภารกิจ: ตามหาทับทิมหลวง (Palace Quest)

ให้นักเรียนใช้บัตรคำสั่งทั้งหมดเพื่อผ่านด่านที่ยากขึ้น!

📜 รายละเอียดภารกิจ

จุดเริ่ม: ประตูพระราชวัง

จุดหมาย: หีบสมบัติชั้นใน

อุปสรรค: "ทหารยามที่หลับอยู่" (ถ้าเดินผ่านช่องข้างๆ ต้องใช้บัตร Wait 5 วินาที เพื่อไม่ให้ตื่น)

ช่องพิเศษ: "บ่อน้ำ" (ต้องใช้บัตร Jump เพื่อกระโดดข้าม)

💎 โบนัสท้าทาย (Expert Mode)

ใช้บัตร Loop ร่วมกับ บัตรตัวเลข เพื่อทำให้ชุดคำสั่งสั้นที่สุด (เช่น เดินหน้า 3 ครั้ง แทนการวางบัตร 3 ใบ)

👣 ขั้นตอนการจัดกิจกรรมภาคสนาม (Physical Setup)

1. การเตรียมพื้นที่ (Setup)

  • ใช้ **เทปกาว (Masking Tape)** ตีเส้นตารางขนาด 5x5 บนพื้นห้อง (ขนาดช่องละ 50x50 ซม.)
  • วาง **ก้อนหิน (อุปสรรค)** และ **ขุมทรัพย์** ตามแผนที่ในภารกิจ
  • กำหนดจุด Start (จุดเริ่มต้น) ให้ชัดเจน

2. แบ่งบทบาทหน้าที่ (Roles)

  • Programmer (1 คน): ผู้วางแผนและจัดลำดับบัตรคำสั่ง
  • Robot (1 คน): ผู้เดินตามคำสั่ง (ห้ามคิดเอง ต้องทำตามคำสั่งเป๊ะๆ)
  • Checker (2 คน): ผู้ตรวจสอบว่า Robot เดินตรงตามบัตรหรือไม่

🛠️ ขั้นตอนการเล่น (Gameplay Steps)

  1. ช่วงวางแผน (Coding Phase): Programmer นำบัตรคำสั่งที่พิมพ์ออกมา มาวางเรียงกันบนโต๊ะข้างสนามตามลำดับที่ต้องการ (ห้าม Robot เข้าไปดูจนกว่าจะเสร็จ)
  2. ช่วงรันโปรแกรม (Execution Phase):
    • Programmer ชี้ที่บัตรคำสั่งใบแรก แล้วอ่านออกเสียง (เช่น "เดินหน้า!")
    • Robot ก้าวเดินเข้าสู่ตารางตามคำสั่งนั้น
    • Checker คอยดูว่า Robot ก้าวล้นช่องหรือเดินผิดทิศหรือไม่
  3. กฎการรันโค้ด (The Rule): ระหว่างที่ Robot เดิน **Programmer ห้ามพูดแนะนำเพิ่ม** ต้องให้ Robot ทำตามบัตรที่วางไว้เท่านั้น
  4. การแก้บั๊ก (Debugging): หาก Robot เดินชนหิน หรือเดินออกนอกตาราง ให้ตะโกนว่า "BUG!" จากนั้น Robot ต้องกลับไปจุด Start และ Programmer ต้องกลับไปสลับ/แก้ไขบัตรคำสั่งใหม่
💡 คำแนะนำสำหรับคุณครู: ในรอบแรกๆ Robot มักจะแอบ "คิดเอง" (เช่น เห็นหินแล้วเดินหลบเองทั้งที่ไม่มีคำสั่ง) ให้คุณครูเตือนว่า "หุ่นยนต์ไม่มีสมองนะ ต้องรอฟังคำสั่งจาก Programmer เท่านั้น" เพื่อฝึกเรื่องตรรกะที่เข้มงวดครับ
