# Coding for Kids | Game Design Workshop (วิทย์ในวัง)

A professional landing page and workshop portal for the "Coding for Kids" project, part of the "Science in the Palace" (วิทย์ในวัง) initiative. This project is designed for students in Grades 1-6 to explore Game Design using Scratch.

## 🚀 Features

- **Modern UI/UX**: Premium design using Glassmorphism and dark mode aesthetics.
- **Responsive Design**: Optimized for Desktop, Tablet, and Mobile devices.
- **BEM Convention**: CSS structured with Block Element Modifier for scalability.
- **SEO Ready**: Optimized with OpenGraph meta tags and semantic HTML5.
- **Interactive Timeline**: Visual guide for the 6-hour workshop schedule.
- **Coding Recipes**: Step-by-step visual code cards for students.

## 📂 Project Structure

```text
coding4kid/
├── assets/
│   └── img/            # Image assets (Hero, Code Cards, etc.)
├── css/
│   └── style.css       # Main stylesheet (BEM naming)
├── js/
│   └── main.js         # Core logic and animations
├── index.html          # Main workshop portal
└── README.md           # Project documentation
```

## 🛠️ Technology Stack

- **HTML5**: Semantic structure.
- **Vanilla CSS3**: Custom properties (variables), Flexbox, and Grid.
- **Vanilla JavaScript**: ES6+ logic and Intersection Observer API.
- **Google Fonts**: Anuphan and Outfit for premium typography.

## 📖 Usage

1. Clone or download the repository to your local server (e.g., XAMPP htdocs).
2. Open `index.html` in any modern web browser.
3. Students can access the "Coding Recipes" section to follow game logic during the workshop.
